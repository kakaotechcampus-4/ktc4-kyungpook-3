# M3. 회의·전사·AI 결과 수신

[전체 계획](../backend-plan.md)의 M3 절을 옮긴 마일스톤 계획이다(기준일 2026-10-02). 이후 진행과 검증 결과는 [결과](result.md)에 있다. 결정 기록은 [basis-for-decision](basis-for-decision/)에 있다.

## 범위

- 회의 생성·종료·실패·상태 조회
- 회의 목록·회의록 조회
- 전사 저장 API
- 화자 매핑·표시 이름 fallback
- 전사 근거와 추출 항목 연결
- 추출 등록 멱등 처리
- 담당자 매칭·게이트
- AI create/update 결과 수신
- 임베딩·유사 태스크 검색
- 회의 요약
- 참석자
- 진행률·처리 완료 시각

## 작업

- 선택적 구조화 요약 입력을 추출 계약에 추가해 저장·조회까지 연결한다.
- 참석자 정보를 별도로 저장해 말하지 않은 참석자와 웹 업로드 참석자도 보존한다.
- 전사·추출 결과가 비어 있어도 단계 완료를 표현할 수 있도록 처리 상태를 보완한다.
- 녹음 종료와 처리 완료 시각을 구분한다.
- AI 호출 순서와 재전송 계약을 검증한다. 전사 저장과 추출 등록의 중간 실패를 포함한다.
- 기존 AI 결정대로 자동 복구 중에는 `processing`, 재시도 소진 시에는 `failed`를 유지한다.
- 로컬 음성의 화자 라벨을 Discord UID와 혼동하지 않도록 입력 어댑터를 구분한다.

## 완료 기준

실제 AI 결과로 요약·전사·참석자·근거·태스크·승인 요청이 연결되고, 재전송해도 중복 결과가 생기지 않는다.
