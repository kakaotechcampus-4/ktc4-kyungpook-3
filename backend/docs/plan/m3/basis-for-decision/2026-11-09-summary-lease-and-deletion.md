# 요약 임대와 삭제 경계

- 기록일: 2026-11-09
- 관련 작업: PR #560 충돌 통합과 자동 요약 활성화. M3 계획 파일은 비어 있어 새 완료조건을 만들지 않는다.

## 문제와 제약

PR의 요약 큐는 요청 표시만 확인해 첫 임대가 끝난 뒤 도착한 결과도 저장했다. 새 요약 테이블은 develop의 회의 삭제·계정 탈퇴와 함께 정리되지 않았다. 요약은 일반 워커의 처리 자리를 보유하고 다음 바퀴도 기다리게 했다. 사용자 목표는 최신 기능을 보존해 병합하고 요약을 켜는 것이다.

## 실제 검토한 선택지

기존 Extraction 큐에 임대 토큰 hash 한 칸을 더하는 안, 기존 시각·시도 값을 작업 세대로 직렬화하는 안, 별도 SummaryJob 표를 만드는 안을 비교했다. 시각 비교 안은 모든 호출자가 정확한 UTC 직렬화와 세 값 비교를 알아야 한다. 별도 표는 이번 두 번 재시도 규약에 비해 크다.

통합 후 실제 API 검사에서는 탈퇴 전 토큰에 최신 세대 헤더만 붙이면 저장이 허용됐다. 토큰 hash에 발급 세대를 결합하는 안과 탈퇴 코드에서 요약 토큰을 일괄 비우는 안을 비교했다. 전자는 세대가 바뀌는 모든 경로를 별도 정리 코드 없이 막는다. 후자는 탈퇴 코드가 요약 임대 상태까지 알아야 한다.

스케줄링은 일반 semaphore만 제거하고 계속 await하는 안과, 진행 중 작업 하나를 보유하고 다음 바퀴를 돌리는 안을 비교했다. semaphore만 제거해도 main loop는 요약을 기다린다. 실제 SummaryRunner와 Event로 막은 FakeLLM으로 다음 pass가 시작되지 않는 반례를 확인했다.

## 선택과 이유

Extraction의 기존 요청·시도·임대는 유지하고 claim마다 난수 토큰을 발급한다. DB에는 발급 당시 `identity_epoch`와 토큰을 결합한 SHA-256만 보관한다. PUT은 잠근 workspace의 현재 세대로 hash를 계산해 비교한다. 세대가 바뀌면 최신 헤더를 붙여도 이전 토큰은 `applied=false`다. force나 다음 claim도 과거 결과를 무효화한다. AI는 claim의 identity_epoch를 입력 GET과 PUT에 고정하며, 이전 세대 헤더는 409로 거절한다. 토큰 없는 저장 우회는 남기지 않는다.

claim은 기존 worker gate 이후 공간·회의·추출 순으로 잠근다. PUT과 삭제도 공간에서 먼저 직렬화한다. 회의 삭제는 요약 서비스의 정리 함수를 호출해 결정과 연결, 고아 주제, 다른 요약의 replaces 사본을 지운다. 생존 Task를 보존하면서 삭제 원문 링크를 감춘다. 공동 자유문장의 이름을 문자열 매칭으로 지우지는 않는다.

요약은 `_summary_task` 한 개로 예약하고 일반 처리의 semaphore와 current 값을 공유하지 않는다. 종료 신호 뒤에는 예약하지 않으며 진행 중 요약은 하트비트를 유지한 채 끝까지 기다린다. 별도 요약 무한 루프는 만들지 않는다.

독립 PostgreSQL 검사에서는 그래프의 쿼리 사이에 회의가 추가·삭제되면 서로 다른 회의 ID 집합을 합치다 KeyError가 났다. 전체 요청의 격리 수준을 바꾸는 대신 로드한 live 회의 사전을 이번 응답의 참조 범위로 선택했다. 앞서 읽은 태스크 연결과 뒤에 읽는 주제 연결을 모두 이 범위에 한정한다. 동시에 추가된 회의는 다음 조회에 포함하며 삭제된 회의의 태스크 업무는 남긴다.

## 장단점과 감수한 제약

기존 두 번 시도와 15분 임대, ready 우선 표시와 pending 1시간 제한을 보존한다. BE와 AI의 token·epoch 계약을 함께 배포해야 한다. 작업 이력 전체를 DB에 남기지는 않는다. 스위치 OFF 중 쌓인 pending은 ON 뒤 과금 처리하며 임의로 비우지 않는다. 이미 저장한 공동 자유문장의 이름 익명화 범위는 기존 정책의 한계로 남는다.

## 영향 범위와 재검토 조건

요약 서비스·봇 API·AI 클라이언트·재처리 명령·회의 삭제·프로젝트 맵 읽기가 영향을 받는다. 호출별 비용·작업 이력이 필요하거나 여러 AI 워커를 운영하면 별도 작업 표와 워커 분할을 다시 검토한다.
