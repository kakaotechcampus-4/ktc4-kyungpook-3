# M7. 운영 배포·관찰·복구

[전체 계획](../backend-plan.md)의 M7 절을 옮긴 마일스톤 계획이다(기준일 2026-10-02). 이후 진행과 검증 결과는 [결과](result.md)에 있다. 결정 기록은 [basis-for-decision](basis-for-decision/)에 있다.

## 범위

- API·DB 운영 컨테이너 구성
- API 내부 Notion·임베딩 워커
- AI 봇·별도 워커 모드
- 전체 서비스 배포 결합
- HTTPS·OAuth 운영 주소
- DB 백업·복원·배포 복귀 절차
- 장기 처리·실패 작업·디스크 관찰

## 작업

- 단일 EC2에서 프록시·API·DB·봇·AI 워커의 실행 경계를 확정한다.
- 현재 구조에서는 API 프로세스 1개를 유지한다. AI는 별도 worker 모드를 기본 제안으로 삼고 메모리를 실측한다.
- CI 산출물 배치, 환경변수, 마이그레이션, 재시작과 이전 버전 복귀 절차를 작성한다.
- DB 백업·복원을 검증한다.
- 장기 `processing`, Notion 실패 작업, 워커 heartbeat, 디스크 사용량을 관찰한다.
- 민감한 본문 대신 요청·회의·작업 ID로 장애를 추적한다.
- 실제 계정의 OAuth·Discord·STT·Notion 연결을 최종 검증한다.

## 완료 기준

배포와 재시작 후 데이터·작업이 보존되고, 장애 복구 절차를 다른 팀원이 재현할 수 있다.
