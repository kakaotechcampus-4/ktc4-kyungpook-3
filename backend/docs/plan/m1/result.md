# M1 인증 변경 검증 결과

## 작업 근거와 요약

2026-11-08 사용자 요청으로 PR #454의 백엔드 변경을 최신 `develop`과 대조했다. M1의 `plan.md`는 비어 있어 마일스톤 완료를 판정하지 않는다. 기존 구현과 검증 기록은 [가입 인증 진행 기록](basis-for-decision/2026-11-06-kakao-login-progress.md)에 있다.

## 실제 구현 및 관련 코드

- 가입 인증 마이그레이션 `d2f6b81c4e07`의 부모를 최신 `develop`의 `5d2e8a41c7b3`으로 연결했다. 기존 읽음 위치 및 승인 임베딩 마이그레이션을 유지하며 단일 head로 만든다.
- `AuthShell` 병합 충돌은 최신 공통 스타일 모듈과 시작 포커스 속성을 유지하고, 이 PR의 모바일 클래스를 `styles.ts`로 옮겨 해결했다. 화면 기능을 추가하지 않았다.
- 코드 확인 뒤 발송 제한 유지, 카카오 대기 쿠키 삭제, 최초 연결 알림 및 메일 미설정 로그의 기존 수정과 테스트를 확인했다.

## 완료조건 확인

계획에 완료조건이 없어 충족 판정을 추가하지 않는다. 이번 작업은 PR #454의 최신 기반 병합과 회귀 검증이다.

## 검증 내역

2026-11-08 로컬 Windows에서 실행했다.

- `python -m alembic heads`는 `d2f6b81c4e07 (head)` 하나를 반환했다.
- `python -m ruff check .` 통과.
- 가입 API·인증 코드·카카오 로그인·OAuth 상태 테스트는 159개 통과, PostgreSQL 미설정으로 114개 건너뜀.
- 전체 백엔드 `pytest -q --tb=short --basetemp=<격리 경로>`는 2427개 통과, 1627개 건너뜀. PostgreSQL 전용 및 조건부 테스트는 실행되지 않았다.
- 프론트엔드 `npm run typecheck` 통과. 인증 관련 Vitest 44개 통과. 병합한 두 스타일 파일의 Prettier와 ESLint 통과.
- Chromium E2E `signup-kakao.e2e.ts`, `login-splash.e2e.ts` 11개 통과. 모바일 가입과 시작 포커스를 포함하며 API는 MSW를 사용한다.

## 계획 대비 변경

최신 `develop`의 스타일 분리와 마이그레이션이 PR 작성 이후 추가되어 기존 기능을 보존하는 병합이 필요했다. API 계약과 인증 정책은 변경하지 않았다.

## 남은 작업과 제한 사항

- 실제 PostgreSQL 마이그레이션 및 동시성은 로컬에서 실행하지 않았다. 새 커밋의 CI로 확인해야 한다.
- 실제 카카오 로그인과 SMTP 송신은 이번 작업에서 실행하지 않았다.
- 프론트엔드 코드 확인 중 단계 변경의 응답 경합 리뷰는 별도 프론트엔드 담당 항목으로 남는다.
- #518도 스키마를 추가한다. 먼저 머지된 PR 이후 다른 PR의 마이그레이션 부모를 다시 연결해야 한다.
