- 대기 중 병합된 #546 메시지 UI와의 조합은 앞서 타입 검사·관련 유닛 83개·실제 브라우저 여정 2개로 별도 검증했다. 이번 수정도 해당 최신 코드와 합쳐 CI를 다시 확인한다.

## 2026-11-08 추가: 가입 상태와 별칭 모의 저장 규약 통합

대기 중 #553이 `develop`에 병합되어 저장 규약과 복원 E2E가 충돌했다. 가입 인증·카카오 상태와 별칭 후보가 각각 모의 저장 버전 17을 사용했고 공통 기반은 16이었다. 기존 구현은 현재 버전만 복원하고 다른 버전은 버리는 정책이므로, 새 마이그레이터를 만들지 않고 통합 버전을 18로 정했다. 이전 모의 캐시가 초기화되는 기존 동작을 유지하며 운영 DB에는 영향이 없다.

- 서로 다른 버전 17 저장본 두 종류를 거부하고, 현재 18에서 가입 코드·증명·카카오 신원·대기 상태와 별칭·승인 별칭 후보를 함께 저장·복원한다.

- TypeScript·ESLint·Prettier·diff 검사와 독립 코드 리뷰를 통과했다. 실제 백엔드와 마이그레이션은 변경하지 않았다. 새 통합 커밋의 전체 CI를 다시 확인한다.

## 2026-11-09 추가: #575 영구 탈퇴의 익명 작성자와 PM 이전 준비

사용자의 #572 진행 요청과 [#575 확정 정책](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/issues/575)을 근거로 `develop@eb22c518`의 별도 작업 트리에서 첫 준비 단위를 구현했다. M1 계획은 비어 있어 마일스톤 완료조건을 만들거나 완료로 판정하지 않는다.

- Member.withdrawn_at와 개인정보 제거 CHECK를 추가했다. 익명 표시명·일반 역할·비활성 상태를 강제하고 User·Discord·Notion 연결을 비운다. 직접 별칭도 제거한다. 기존 명단 비활성화와는 다른 상태다.
- 공동 대화·본문·작성자 참조를 유지하며 PM 목록·읽지 않은 수·읽음을 지원한다. 기존 명단 비활성화의 상세 200·unread 0·읽음 POST 404는 유지한다. 영구 익명 주체의 프로필 수정·초대·발송과 늦은 초안·DM·답장 판단 결과는 거절한다.
- 읽기 전용 탈퇴 계획 서비스는 모든 활성 소속을 보존·단독 공간 삭제·PM 이전 필요로 구분한다. 계정 없는 활성 Discord 팀원도 센다. 실제 원자적 계정 탈퇴 명령은 아직 없다.
- MemberResponse.has_login_account를 추가하고 FE의 로그인 연결 팀원 PM 승격을 지원한다. [현재 API 계약](../../../../frontend/docs/contracts/frontend-api-contract.md)과 [선택 근거](basis-for-decision/2026-11-09-withdrawn-record-actor.md)에 반영했다.
- 마이그레이션 `e575a01c9d42`는 기존 `e576a01c9d42`의 다음 head다. SQLite는 Member 테이블을 재생성하면 자식 기록을 CASCADE할 수 있어 컬럼의 inline CHECK로 추가한다. PostgreSQL은 table CHECK를 사용한다.

검증자는 작성자 실행 뒤 고정된 소스에서 다시 실행했다. 백엔드 API·메시지·읽음·초대·마지막 PM·마이그레이션 회귀 8파일은 **286개 통과, 295개 건너뜀**이다. 건너뛴 항목은 PostgreSQL 환경 등이 필요하며 SQLite 성공을 경합 검증으로 해석하지 않는다. 신규 actor·단독 revision 마이그레이션 13개는 독립 리뷰어도 통과를 확인했다. 마이그레이션 테스트는 FK ON인 축약된 이전 Member와 CASCADE 자식 테이블에서 upgrade·제약 거절·downgrade·자식 본문 보존을 확인한다. 전체 기존 SQLite Alembic 체인은 이전 PostgreSQL vector extension 단계에서 실행 불가이며 이번 테스트가 전체 체인을 대신하지 않는다.

프론트엔드 작성자 검증은 관련 유닛 58개와 최종 관련 10개, 타입검사·lint·빌드가 통과했다. 검증자도 Node 24.21.0 타입검사와 실제 Chromium의 PM 승격·본인 PM 유지·새로고침 후 역할 유지 1개를 재시도 없이 실행했다. 화면과 trace를 확인했고 전용 포트 5291 종료도 확인했다. 이 브라우저 검증은 MSW 저장이며 실제 백엔드 역할 변경과 연결된 E2E 증거는 아니다.

보호 계획·사람의 트러블슈팅 37파일 해시를 보존했다. 신규 코드·테스트를 포함한 소스 해시가 검증 전후 동일했다. 원자적 계정·세션 삭제, 구조화 식별 복사본 전체, 단독 공간 파일·AI 정리, 재가입 전체 흐름, 본인 탈퇴 API·화면은 후속 단위다. 이번 결과는 #575 전체 완료·병합·배포를 뜻하지 않는다.

AI 정리 지연 중의 완료 표시 기준도 확정하지 않았다. 별도 정책 대화로 질문을 전달하려 했으나 도구 오류로 전달되지 않아 사용자 승인으로 취급하지 않는다. 기존 즉시 개인정보 삭제·재가입·새 초대 정책을 변경한 것은 아니다.
