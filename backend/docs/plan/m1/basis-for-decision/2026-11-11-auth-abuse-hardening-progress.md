# 가입 코드 IP 상한, 잠긴 이메일의 재설정, 비밀번호 해시 횟수를 보강했다

- 날짜: 2026-11-11
- 이슈: #691
- 브랜치: fix/691-auth-abuse
- 작성자: 김동우

## 한 일

- 가입 코드 요청(`POST /auth/signup/code`)에 공인 IP 시간당 10회 상한을 더했다. 재설정 IP 제한기에 `scope`·`limit` 인자를 더해 같이 쓰고, 넘으면 429 `SIGNUP_CODE_RATE_LIMITED` `reason: "ip"` 다
- 이미 가입한 이메일인지는 재발송·시간당·전체 제한을 모두 본 뒤에 판단한다
- 로그인이 잠긴 이메일의 재설정 요청은 전체 상한을 보지 않는다. 계정당·IP 제한은 그대로다
- 비밀번호 해시를 600,000회로 올리고 `pbkdf2_sha256$횟수$salt$digest` 로 횟수를 담는다. 옛 형식(260,000회)도 맞춰 보고, 로그인에 성공하면 해시가 그대로일 때만 다시 해시한다. 옛 해시는 모자란 횟수를 더 계산해 응답 시간을 맞춘다
- 보안 설계 문서, backend README, 프론트 계약의 `reason` 목록을 고쳤다. 프론트 코드는 고치지 않았다

## 왜

2026-11-11 보안 점검에서 남의 가입·로그인을 막거나 가입 여부를 알아낼 수 있는 경로가 나왔다. 선택지와 감수한 점은 [결정 기록](2026-11-11-auth-abuse-hardening-decision.md).
