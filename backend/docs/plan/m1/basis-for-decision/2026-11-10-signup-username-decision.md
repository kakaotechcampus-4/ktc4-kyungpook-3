# 모든 계정에 아이디를 두고, 카카오 가입은 카카오만으로 끝낸다

- 날짜: 2026-11-10
- 상태: 결정됨

## 배경

카카오 계정에 이메일이 없는 사용자가 있어 팀원 초대를 이메일 대신 아이디로 찾는 방식으로 옮기려 한다. 그러려면 모든 계정에 아이디가 있어야 한다. 지금 카카오 가입은 카카오가 이메일을 주지 않으면 이메일 코드 인증과 비밀번호를 요구하고, 카카오 이메일이 기존 계정과 같으면 그 계정에 잇는다([카카오 로그인 결정](2026-11-06-kakao-login-decision.md)). 초대가 아이디로 바뀌면 카카오 가입이 이메일을 가져야 할 이유가 없어진다.

## 검토한 선택지

카카오 가입에 이메일을 둘 것인가

- 지금처럼 이메일을 받는다: 이메일 초대를 그대로 받는다 / 이메일 없는 사용자는 코드 인증과 비밀번호를 거쳐야 한다
- 카카오 신원만으로 만든다: 가입 단계가 아이디와 이름뿐이다 / `user.email` 을 비울 수 있게 바꿔야 하고, 아이디 초대 전까지 이 계정은 이메일 초대를 받지 못한다

카카오 이메일이 기존 계정과 같을 때

- 지금처럼 잇는다: 기존 사용자가 카카오로 바로 들어온다 / 카카오 이메일을 계정 소유의 증명으로 믿어야 하고, 잇는 경로와 알림 메일을 계속 유지한다
- 잇지 않고 가입으로 보낸다: 계정을 만드는 곳이 가입 하나로 줄어든다 / 같은 사람이 카카오로 들어오면 계정이 하나 더 생긴다

기존 계정의 아이디

- 이메일 앞부분으로 채우고 설정에서 바꾸게 한다: 다음 로그인 때 막는 단계가 없다 / 사용자가 고르지 않은 아이디가 붙는다
- 다음 로그인 때 고르게 한다: 사용자가 정한 값이다 / 로그인 뒤 막는 화면이 하나 더 든다

## 결정

- 카카오 가입은 대기 쿠키의 카카오 id, 요청의 아이디와 이름만으로 계정을 만든다. 카카오가 이메일을 줘도 저장하지 않고 비밀번호도 없다. 카카오 가입에 `password` 나 `verification_token` 이 오면 400 이다. 프론트에 남은 옛 필드를 바로 드러내려는 것이다
- callback 은 카카오 id 로 이어진 계정만 로그인한다. 같은 이메일의 계정이 있어도 잇지 않고 가입으로 보낸다. 잇는 경로, `oauth_reason=email_exists`, 연결 알림 메일을 지웠다
- 이미 있는 계정의 로그인 방법은 그대로 둔다. 전에 카카오로 가입하며 비밀번호를 정한 계정과 카카오가 이어진 이메일 계정은 두 로그인을 계속 쓴다
- 아이디는 영문과 숫자 4 ~ 20자이고 소문자로 저장해 대소문자를 가리지 않는다. 예약어는 막지 않는다. 아이디를 주소에 쓰는 곳이 없고 사용자가 적어 나중에 막아도 비용이 작다
- 기존 계정은 이메일 앞부분에서 영문·숫자만 남긴다. 4자 미만이면 앞에 `user` 를 붙이고 20자로 자르며, 겹치면 가입 순서대로 숫자를 붙인다
- 중복 확인은 로그인 없이 부르고 내 아이디도 `taken` 이다. 프론트가 지금 아이디와 비교한다
- 가입·탈퇴가 같은 줄에 서는 잠금 키는 이메일이 있으면 `email:<이메일>`, 없으면 `kakao:<카카오 id>` 다. 가입 시점에는 user_id 가 없고, 탈퇴한 뒤 같은 카카오로 다시 가입하는 경우와 같은 잠금을 써야 한다
- 이메일 없는 계정이 있으면 이 마이그레이션의 downgrade 는 오류로 멈춘다. 데이터를 지우거나 가짜 이메일을 넣지 않는다

## 다시 볼 조건

- 아이디 초대가 들어가기 전에 이메일 없는 카카오 사용자가 초대를 받아야 하는 일이 생기면
- 같은 사람이 이메일 계정과 카카오 계정을 따로 갖게 된 사례가 나와 합칠 방법이 필요하면
- 아이디를 프로필 주소처럼 화면 경로에 쓰게 되면 예약어를 다시 본다
