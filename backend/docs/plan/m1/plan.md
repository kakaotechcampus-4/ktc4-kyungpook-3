# M1. 인증·워크스페이스·온보딩·권한

[전체 계획](../backend-plan.md)의 M1 절을 옮긴 마일스톤 계획이다(기준일 2026-10-02). 이후 진행과 검증 결과는 [결과](result.md)에 있다. 결정 기록은 [basis-for-decision](basis-for-decision/)에 있다.

## 범위

- 이메일 가입·로그인·로그아웃·`me`
- 세션 만료·워크스페이스 소속 검사
- 워크스페이스 생성·목록·상세
- 온보딩 단계 저장·재개·건너뛰기
- 팀원·별칭·Discord ID 매핑
- 이름 정규화·계정 범위 중복
- 전체 API의 PM 권한 통일
- 일반 팀원의 확인 필요 정보 비노출
- 내부 API 서비스 인증

## 작업

- 웹 API별로 로그인·소속·PM 권한 표를 만들고 공통 의존성으로 적용한다.
- 승인·반려·되돌리기·팀원 관리·연동 관리의 PM 제한을 서버에서 강제한다.
- 일반 팀원에게 승인 항목·개수·참조 정보가 노출되지 않도록 조회 응답을 제한한다.
- 봇/AI의 회의 생성·종료·실패·추출 등록에 서비스 인증을 적용하고 호출 클라이언트도 함께 변경한다.
- 이름 정규화와 계정 범위 중복 검사를 구현하고 동시 생성도 처리한다.
- 소프트 삭제 후 Discord 계정 재매핑 시 DB 제약과 사전 검사가 일치하도록 수정한다.
- 쿠키 설정과 동일 출처 변경 요청 검증을 로컬·운영 환경에서 확인한다.

## 완료 기준

미로그인·비소속·일반 팀원·PM·서비스 호출자의 허용 범위가 테스트로 고정되고, 기존 온보딩 흐름이 실제 API에서 재개된다.
