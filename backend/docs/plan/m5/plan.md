# M5. 웹 음성 업로드·비동기 처리

[전체 계획](../backend-plan.md)의 M5 절을 옮긴 마일스톤 계획이다(기준일 2026-10-02). 이후 진행과 검증 결과는 [결과](result.md)에 있다. 결정 기록은 [basis-for-decision](basis-for-decision/)에 있다.

## 범위

- multipart 업로드 경로·202 응답
- 처리 중 회의 검사
- 파일 저장·AI 전달
- 참석자 파싱·소속 검증·저장
- 용량·길이·형식 검증
- Notion 연결 차단
- 업로드 작업 복구·임시 파일 정리

## 작업

- 제목·회의 날짜·참석자를 검증하고, 제한을 적용하며 파일을 스트리밍 저장한다.
- 웹과 Discord 경로에 공통으로 적용되는 워크스페이스 처리 제한을 원자적으로 구현한다.
- 업로드 접수·파일 저장·AI 전달 상태를 영속적으로 기록해 재시작 시 복구한다.
- AI의 기존 후처리·복구 흐름을 활용하는 업로드 어댑터를 추가한다.
- 최종 성공·실패 시 임시 파일을 정리한다.
- 실패 회의는 목록에서 제외하되 상태 조회로 오류를 전달하고 처리 제한을 해제한다.

## 완료 기준

웹 업로드가 영구 `processing`에 머무르지 않고 성공 또는 실패로 끝나며, 이후 업로드가 가능하다.
