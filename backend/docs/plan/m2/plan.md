# M2. 태스크·승인·변경 이력·동기화

[전체 계획](../backend-plan.md)의 M2 절을 옮긴 마일스톤 계획이다(기준일 2026-10-02). 이후 진행과 검증 결과는 [결과](result.md)에 있다. 결정 기록은 [basis-for-decision](basis-for-decision/)에 있다.

## 범위

- 태스크 생성·목록·상세·수정
- 변경 이력·행위자 기록
- 이력 되돌리기
- 승인 생성·조회·승인·반려
- AI 수정 제안의 기준값 저장
- 승인 충돌·확인 후 재승인
- Notion outbox·워커
- Notion 재시도·중복 생성 방지
- 역할 제한·실제 동시 변경 검증
- 화면의 반영 상태와 서버 의미 일치

## 작업

- M1의 PM 권한을 태스크 쓰기·승인·되돌리기·수동 동기화 재시도에 적용한다.
- 동시 승인, 승인과 수동 수정, 되돌리기와 수정의 경합을 PostgreSQL에서 검증하고 필요한 잠금·조건부 갱신을 보완한다.
- 승인 충돌 시 승인 상태·태스크·이력·outbox가 부분 반영되지 않는지 확인한다.
- `pending / synced / failed`와 동기화 버전을 프론트 표시 기준으로 정리한다.
- 최근 반영 이력에 필요한 작업 연결·성공 시각을 제공한다.
- 연결 해제·재연결 전후의 대기·실패 작업 처리 규칙을 M4와 맞춘다.

## 완료 기준

권한이 있는 사용자만 변경할 수 있고, 충돌·재시도에도 DB 이력과 Notion 반영 작업이 일관되게 남는다.
