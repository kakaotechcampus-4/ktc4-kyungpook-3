Mascot · usage

매스를 쓰는 법

포즈는 커서를 따라가지 않고 상태 머신으로만 바뀝니다. 랜딩과 채팅 아바타에만 쓰고, 승인 워크벤치 본문에는 넣지 않아요. 타이머 버튼에 붙는 움직임은 눌림 하나뿐입니다.

모션 규칙

구현은 frontend/docs/mascot/mascot.js
  • 2D만. 구면 투영, 원근 스케일, 몸 회전(yaw), 스펙큘러, 드롭 섀도 없음.
  • 고개를 돌리는 건 Inner의 평행이동입니다. 메쉬를 돌리지 않아요.
  • 전환은 스프링 없이 지수 ease-out — 오버슈트 없음.
  • 깜빡임은 2.5–4초마다 눈 높이만 접었다 폄. 가끔 두 번 연속.
  • 버튼 눌림: 몸 쪽 아랫변 고정, 윗면만 내려왔다 복귀. 5–8초마다, 클릭 시에도 1회.
  • 다이얼: 버튼 안 줄무늬만 스크롤. 버튼째로 돌리거나 몸을 돌리지 않습니다.
  • 말하는 중에도 입은 생기지 않습니다. 정면 포즈에 아주 작은 세로 bounce만.
  • prefers-reduced-motion이면 정지 프레임 — 깜빡임·눌림 없음, 줄무늬는 보이되 안 움직임.

버튼 눌림

타이머 버튼에 붙는 유일한 움직임 · mascot.js _cap()
쉼scale(1, 1.00)

버튼이 제 높이로 서 있는 기본 상태입니다.

내려가는 중scale(1, 0.79)

윗면만 아래로. 아랫변은 붙박이라 몸과의 간격이 그대로입니다.

눌림scale(1, 0.58)

최대 42%까지 눌립니다. 여기서 같은 시간을 들여 되돌아옵니다.

값
누르는 깊이윗면 42% · scale(1, 0.58)
회전 축몸 쪽 아랫변 (translate 0 h/2 -> scale -> translate 0 −h/2)
한 번 걸리는 시간0.26초 · 내려갔다 복귀
자동5–8초마다 1회
클릭즉시 1회
reduced-motion없음 · 정지 프레임
  • 누르는 건 버튼 하나뿐입니다. 몸도 얼굴도 눈도 움직이지 않아요.
  • 아랫변이 고정이라 몸과의 간격은 변하지 않습니다. 눌러도 버튼이 몸에 닿지 않습니다.
  • 포즈가 바뀌어도 눌림은 그대로 돕니다 — 포즈별 capX·capY·rot 위에 얹히는 변형입니다.
  • 회전(rotate)은 눌림 앞에 옵니다. 순서를 바꾸면 버튼이 접선에서 벗어납니다.

어두운 배경

잉크 마크는 어두운 면 위에 그대로 올리지 않음

흰 카드 위에. 링과 버튼이 배경에서 떨어집니다.

바로 얹으면 링도 버튼도 사라지고 흰 얼굴만 떠 보입니다.

하지 말 것

여섯 가지 그림 + 나머지
✕버튼을 몸에 붙이기

같은 잉크라 간격이 없으면 버튼이 아니라 혹으로 읽힙니다. 눌릴 때도 아랫변이 고정이라 간격은 그대로 남습니다.

✕버튼을 오른쪽 정수리로

다섯 키 모두 capX가 음수입니다. 얼굴이 오른쪽을 봐도 버튼은 10–12시에 머뭅니다.

✕다이얼 = 몸 전체 회전

감기는 건 버튼 안 줄무늬뿐입니다. 몸이나 버튼을 돌리면 굴러가는 공이 됩니다.

✕흰 눈 · 검은 얼굴

팔레트가 반대입니다. 얼굴과 줄무늬는 언제나 흰색, 몸·눈·버튼이 잉크 하나.

✕가늘게 = 세로 눈 누르기

정면 눈을 scaleY 하면 이렇게 됩니다. 가늘게는 44×12 가로 캡슐로 다시 그립니다.

✕위 포즈에서 두 눈 같은 각도·크기

먼 눈이 더 작고 더 기울어야 합니다. 같으면 평면 스티커처럼 보여요.

  • 회색으로 채운 입체 구 — 이 캐릭터는 플랫 마크입니다.
  • 커서 따라가기 — 의도적으로 뺐습니다.
  • GIF · Lottie 루프만 쓰기 — 상태 전환이 안 됩니다.
  • 위를 볼 때 Inner를 크게 올려 아래에 큰 초승달 만들기.
  • 그라데이션 · 광택 · 그림자 · 입 · 눈썹. 산호 팔레트는 Figma 컬러 스터디로만.
  • 좌우 포즈를 거울로 맞추지 않기. 새 포즈는 프레임을 보간하지 말고 규칙으로 새 키를 정의합니다.
