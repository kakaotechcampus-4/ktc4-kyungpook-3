# 캘린더 상태는 색에 아이콘과 낭독 이름을 더해 구분한다

- 기록일: 2026-11-05
- 관련 마일스톤: M8-A(#243) 태스크 보기, 이슈 #338
- 근거: 2026.10.30 접근성 상세 이슈 보고서(KWCAG 2.2 '색에 무관한 콘텐츠 인식') 슬라이드 4·10·13
- 결정 주체: **표식 모양은 디자인 합의 전 기본값이다.** 구현 워커가 골랐고 사용자·디자인 결정이 아니다.

## 문제와 제약

- 캘린더 칩은 배경색과 글자 굵기로만 `확인 필요`(먹)·`마감 임박`(강조색)·`진행 중`(회색)을 나눴다. `danger`와 `warn`은 같은 모양이다. 범례도 색 견본뿐이었다.
- 칩 링크 이름은 제목과 담당자뿐이라 화면 낭독기에는 상태가 전해지지 않았다. 완료 칩의 취소선도 낭독되지 않는다.
- 색 클래스는 #336(명도 대비)이 맡는다. 이 결정은 색을 바꾸지 않고 표식만 더한다.
- 아이콘은 새로 그리지 않고 `shared/ui/icon`의 것을 쓴다.

## 실제 검토한 선택지

| 항목 | 선택지 | 고른 것과 이유 |
|---|---|---|
| 마감 임박 표식 | `alert`(원 안 `!`), `clock`(시계) | `alert`. 기한 지남·막힘도 이 칩에 들어가 시간보다 '경고'가 맞다. 팀 화면 `먼저 챙길 것`도 같은 아이콘이다 |
| 확인 필요 표식 | `info`(원 안 `i`), `edit`(연필), `eye`(눈) | `eye`. `info`는 12px에서 `alert`와 같은 원 모양이라 흑백에서 갈리지 않는다. 연필은 '고쳐야 함'으로 읽힌다. 눈은 '봐야 함'에 가깝고 원과 윤곽이 다르다 |
| 진행 중·할 일 | 표식 둠 / 없음 | 아이콘은 없음. 기본 상태이고, 표식이 있는 두 상태와 '없음'으로 갈린다. 낭독 이름에는 `진행 중`·`할 일`을 넣는다(독립 검증에서 진행 중 칩 이름에 상태가 빠진 것을 찾아 고쳤다. 아이콘 유무와 낭독 상태를 같은 값으로 다룬 탓이었다) |
| 완료 | 아이콘 더함 / 취소선 유지 | 취소선 유지. 이미 모양으로 구분되므로 낭독 이름에만 `완료`를 더한다 |
| 낭독 이름 | 숨김 텍스트(`sr-only`) / 링크에 `aria-label` | `aria-label`. 처음에는 숨김 텍스트로 `마감 임박, `과 제목·담당자 사이 `,`를 넣었다. jsdom에서는 '마감 임박, 회원가입 화면, 박민수'였지만 Chromium(Playwright ARIA 스냅샷)은 칩 안의 제목·담당자를 따로 줄을 차지하는 블록으로 보고 '마감 임박, 회원가입 화면 , 박민수'로 이었다. 낭독은 같지만 시험 환경과 브라우저의 이름이 달라 시험이 실제를 증명하지 못한다. 그래서 보이는 글자(상태·제목·담당자)를 이어 `aria-label`을 직접 짓는다. 보이는 제목과 담당자가 이름에 그대로 들어 있어 음성 입력으로도 부를 수 있다 |
| 마감일 없음 칸의 태스크 | 상태 생략 / 태스크 상태 이름 | 태스크 상태 이름(`할 일`·`진행 중`·`막힘`·`완료`, `TASK_STATUS_LABEL`). 이 칸은 마감이 없어 `마감 임박`으로 묶지 않는다 |
| 표의 위치 | 칩·범례마다 따로 / 한 표 | `CalendarView.tsx`의 `MARK` 한 표. 칩(`CHIP[tone].mark`)·링크 이름(`chipName`)과 범례(`LegendItem`의 `icon`)가 같은 값을 읽는다 |

## 같은 기준을 적용한 다른 화면

- 보드(`BoardView.tsx`): `위험`·`주의`·`막힘` 글자 배지가 이미 있어 그대로 둔다.
- 간트(`GanttView.tsx`): 막대 안에 `위험`·`주의`·`완료` 글자가 있고, 진행 중(채움)·시작 전(테두리)·확인 필요(점선)는 모양으로 갈린다. 그대로 둔다.
- 팀원 목록(`MemberList.tsx`): 팀원 배지는 글자(`위험`·`주의`·`정상`)가 있다. 맡은 일의 기한 지난 마감은 먹 글자색으로만 갈렸으므로 캘린더 `마감 임박`과 같은 `alert` 아이콘을 붙였다(낭독용 `기한 지남`은 이미 있었다). 날짜 칸을 44px에서 56px로 넓혔다. 다른 위젯이라 `MARK` 표를 가져오지 않고 같은 아이콘 이름을 쓴다(FSD상 위젯끼리 가져오지 않는다).

## 바꾸려면

디자인이 다른 표식을 정하면 `CalendarView.tsx`의 `MARK`에서 아이콘 이름만 바꾼다. 칩과 범례가 함께 바뀐다. 팀원 목록의 아이콘은 `MemberList.tsx`의 `TaskRow`에서 따로 바꾼다.
