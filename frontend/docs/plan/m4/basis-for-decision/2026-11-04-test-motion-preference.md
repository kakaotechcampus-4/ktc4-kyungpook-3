# UI 통합 테스트의 기본 모션 선호를 고정한다

- 기록일: 2026-11-04
- 관련 범위: M4 온보딩·접근 가드 테스트 재검증, PR #312

## 문제와 근거

사용자가 보고된 테스트 실패 4건의 해결을 요청했다. 기본 5초 제한으로 네 사례를 분리 실행하자 3개는 통과하고 PM 선택·공간 생성 사례가 실패했다. 임시 추적에서는 이름 입력 도중 제한을 넘겼으며 생성 POST·온보딩 PATCH는 시작되지 않았다.

기본 jsdom에는 `matchMedia`가 없어 실제 마스코트는 모션 허용 상태로 프레임을 계속 예약한다. 추적 실행에서는 rAF 예약 36회가 기록됐다. rAF 콜백만 멈춘 대조는 같은 제한에서 통과했다. 이 결과를 다른 세 사례의 원인 확정이나 제품 애니메이션 결함으로 해석하지 않는다.

## 선택과 이유

일반 UI 테스트의 브라우저 선호를 `prefers-reduced-motion: reduce`로 명시한다. [테스트 환경](../../../../src/shared/test/setup.ts)의 `beforeEach`가 고정 `MediaQueryList`를 설치한다. 정확한 모션 감소 쿼리만 참이며 다른 쿼리는 거짓이다.

기존 [마스코트 테스트](../../../../src/shared/ui/mascot/Mascot.test.tsx)는 모션 허용·감소·실시간 설정 변경·구독 해제를 자체 fixture로 계속 검증한다. API 누락 사례는 `undefined`를 명시한다. 새 회귀 테스트는 기본 환경의 실제 컴포넌트가 프레임을 예약하지 않는지 확인한다.

설치·복원을 테스트마다 복사하는 안과 공유 선호 상태·이벤트 API를 만드는 안을 비교했다. 고정 기본값과 기존 테스트별 override만 있으면 되므로 별도 모듈이나 변경 API를 추가하지 않았다. 매 테스트 앞에 설치하므로 기존 종료 훅의 `unstubAllGlobals` 이후에도 기본값을 복원한다.

## 영향과 제한

제품 코드, 5초 테스트 제한, 사용자 흐름 단언을 유지한다. 전역 rAF나 실제 타이머를 대체하지 않아 프레임 기반 레이아웃 측정도 유지한다. 모션 자체를 검증하는 새 테스트는 선호를 명시적으로 덮어써야 한다.

이번 선택은 Node 테스트 환경의 기본값이다. 실제 브라우저의 사용자 선호와 애니메이션은 변경하지 않는다. 검증 결과와 과거 실패를 구분해 [M4 결과](../result.md)에 기록한다.
