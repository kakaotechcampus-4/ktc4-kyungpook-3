# 금지 색·굵기를 주석에 적어도 되는가

- 날짜: 2026-09-16
- 상태: 열린 문제

## 고민

토큰 파일은 `#000000`과 `font-medium`을 **쓰지 말라고** 주석에 적는다.
완료 조건 grep은 `src/`에서 그 문자열이 0건이어야 한다고 한다. 주석이 grep에 걸린다.

실제 선언·유틸은 0건이다. dist CSS에도 없다.

## 지금

주석을 스펙 문장 그대로 둔다. “쓰지 마라”는 설명을 지우면 파일이 스펙과 달라진다.
컴포넌트 TSX/CSS에는 그 문자열을 선언으로도 주석으로도 새로 넣지 않는다.

## 다시 고민할 때

검증 grep을 주석 제외로 바꿀지, 빌드된 CSS만 볼지는 게이트를 손볼 때 정한다. 구현 중에 주석을 지워 grep을 맞추지 않는다.
