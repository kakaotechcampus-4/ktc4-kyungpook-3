[정책 안내](../../../../docs/policy/README.md)에 확정한 제품 정책과 남은 확인을 구분했다. [개인정보처리방침](../../../../docs/policy/privacy.md)과 [이용약관](../../../../docs/policy/terms.md)은 서비스 화면에 게시하기 전의 준비본이다.

## 검증

문서 작업의 시작 기준은 `7cd46bab0c11c8fa14576572e68854ce5d22c075`이며 작업 시작 시 해당 폴더에 미커밋 변경이 없음을 확인했다. 2026-11-09 문서 상대 링크·앵커 검사, 한글 인코딩 검사와 `git diff --check`를 수행했다. 계획·트러블슈팅 등 보호 문서 245개의 작업 시작 해시를 대조해 변경이 없음을 확인했다.
