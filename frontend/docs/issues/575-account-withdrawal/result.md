# #575 계정 탈퇴를 위한 PM 이전 준비

2026-11-09. 사용자 요청과 [#575](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/issues/575)에 따른 첫 준비 단위다. 계정 탈퇴 API·화면 자체는 아직 구현하지 않았다. 전체 FE 계획과 이슈 목록은 수정하지 않는다.

## 구현

- MemberResponse.has_login_account를 hasLoginAccount로 매핑한다. PM 이전 대상이 웹에 로그인할 수 있는지 User ID 없이 구분한다.
- 팀 화면에서 PM이 로그인 계정이 연결된 일반 팀원에게 PM 권한을 부여한다. 확인창에서 팀 설정·업무 승인·초대 권한과 본인의 PM 권한 유지를 안내한다.
- 기존 PATCH 역할 변경을 사용한다. 대기 초대·동시 변경 등 서버 오류를 표시하고 성공 시 팀원·공간 조회를 갱신한다. 모의 저장·fixture도 새 필드와 역할 변경을 지원한다.

[대표 계약](../../contracts/frontend-api-contract.md)에 현재 코드 동작과 아직 완료되지 않은 전체 탈퇴 범위를 구분했다. 백엔드의 익명 기록 주체·계획 서비스 결과는 [M1 결과](../../../../backend/docs/plan/m1/result.md)에 있다.

## 검증

작성자가 관련 유닛 58개와 최종 관련 10개, 타입검사·lint·빌드를 통과했다. 검증자는 Node 24.21.0 타입검사와 실제 Chromium에서 PM 권한 부여·본인 PM 유지·새로고침 후 역할 유지 1개를 다시 실행해 통과했다. 재시도는 없으며 확인창·승격 후 화면·trace를 확인했다. 전용 개발 서버 포트 종료도 확인했다.

Chromium의 API·저장은 MSW다. 실제 제공자·운영 DB·실제 백엔드와 연결된 통합 E2E를 확인했다는 뜻이 아니다. 독립 리뷰와 백엔드 회귀에서도 이 준비 단위를 전체 계정 탈퇴 완료로 평가하지 않았다.

## 남은 범위

본인 탈퇴 API·화면, 여러 공간의 원자적 조건 재검사·계정 정리, 세션·푸시 삭제, 구조화 개인정보의 전체 정리, 단독 공간 파일·AI 정리, 재가입 후 새 초대 검증이 남는다. 이번 단위는 병합·배포하지 않았다.

AI 정리가 지연될 때의 완료 표시 기준은 미확정이다. 별도 정책 대화로 보낼 질문이 도구 오류로 전달되지 않았으며, 사용자가 새 표시안을 승인했다고 기록하지 않는다.
