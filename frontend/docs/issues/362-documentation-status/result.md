## 검사와 제한

- 변경 Markdown 11개의 상대 파일·디렉터리와 조각 식별자 240개를 검사했고 오류는 없었다. 외부 URL의 현재 접속 여부는 검사하지 않았다.
- 작업 시작·종료의 공통 보호 범위 37개 파일의 SHA-256이 같다. 별도 이름을 쓰는 AI 전체 계획도 시작 기준 커밋과 내용이 같다. 파일 삭제·이동은 없다.
- `git diff --check`를 통과했다. 애플리케이션·테스트·CI 코드는 변경하지 않았다. 문서만 변경해 기능 테스트는 재실행하지 않았다.
- 이번 문서 점검은 새 실서버·공급사·iOS 검증이나 현재 배포 성공을 증명하지 않는다. M6·M7·M8과 BE 마일스톤의 완료조건을 새로 만들거나 전체 완료를 선언하지 않았다.
- #362의 전체 이슈 종료는 후속 병합 결과와 운영 인수인계의 최종 확인을 포함해 별도로 판단한다.
