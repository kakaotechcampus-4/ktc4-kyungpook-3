- 이슈: #313
- PR: #334
- 브랜치: feature/313-gpu-stt-serving
- 작성자: 김동우

## 한 일

- AWS 서울 g4dn.xlarge 에 vLLM 0.19.1 로 large-v3 와 turbo 를 올려 Elice 기준선과 같은 시나리오를 돌렸다. 코드는 바꾸지 않았다.
- 볼륨 초기화 속도를 바꿔 AMI 콜드 스타트를 쟀다.
- 결과를 [측정 문서](../../../stt/eval/results/2026-11-04-gpu-serving/README.md) 에 정리했다.
- 비용 모델, 손익분기, 12월까지 예산을 [0039](2026-11-04-0039-gpu-stt-server.md) 에 남겼다.

## 왜

Elice 장애 때 폴백인 운영 CPU 는 회의 1분당 81 ~ 87초가 걸린다. GPU 서버를 장애 대응이나 주 전사기로 둘지 실측으로 정해야 했다. 판단 근거는 0039 에 있다.

## 결과

| 항목 | Elice | T4 large-v3 | T4 turbo |
|---|---|---|---|
| 6인 CER m01 / m02 | 6.52% / 4.86% | 6.52% / 4.86% | 6.65% / 4.99% |
| 9/29 실녹음 CER | 21.2% | 21.1% | 20.2% |
| 62.42분 합성 전사 | 65.07초 | 159.8초 | 68.9초 |
| 콜드 스타트, 기본 gp3 | | 22.1분 | |
| 콜드 스타트, 초기화 300MiB/s | | 5.0분 | |
| 호출 실패 | 0 | 0 | 0 |

측정에 든 돈은 인스턴스 시간으로 계산해 약 $1.6(₩2,200)이다. 실제 청구는 아직 대조하지 못했다.
