# GPU 전사 서버 전환 리허설

- 날짜: 2026-11-07
- 이슈: #393
- PR: #528
- 브랜치: `docs/393-gpu-stt-rehearsal`

## 한 일

운영 워커를 GPU 서버로 옮겨 저장된 6인 회의 하나를 처리하고 Elice 로 되돌렸다. 전환과 복귀 경로는 동작했지만 전사 15구간 중 2구간이 오류 없이 비었다. 코드는 바꾸지 않았고 `deploy/gpu-stt/README.md` 에 결과와 주의점을 적었다.

## 왜

[#410](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/pull/410) 은 워커를 쓰지 않는 일회성 호출만 쟀다. drop-in 과 워커 재시작, 복귀가 실제로 통하는지 확인하지 못했고 측정용 합성 회의는 정확도 근거가 아니다.

## 결과

회의는 약 2분 13초(132.66초)이고 음성은 70.6초를 보냈다. 원본은 2026-11-04 에 Elice 로 처리한 같은 회의다.

| 단계 | 값 |
|---|---|
| `on --hours 1` | 22초 |
| `/health`, 키 호출 | 둘 다 200 |
| 전환 워커 재시작 | 1초 |
| 복제부터 `handed_off` | 73초 |
| 복귀 워커 재시작 | 1초 |
| `off` | 396초, `stopped` |

한 번 잰 값이다. 워커가 GPU 주소를 쓴 근거는 프로세스 환경값과 처리 중 GPU 서버로 열린 연결 1개다. 서버 쪽 로그는 볼 수 없다.

| 항목 | 원본 (Elice) | 리허설 (GPU) |
|---|---|---|
| 호출 / 실패 / 재시도 | 15 / 0 / 0 | 15 / 0 / 0 |
| 내용이 있는 구간 | 15 | 13 |
| 전사 글자 수 | 521 | 461 |
| 전사 시간 | 5.25초 | 12.8초 |
| 추출 시간 | 약 60초 | 48.99초 |
| 추출 항목 | 6 | 5 |
| 자동 / 검토 / 보류 | 0 / 5 / 1 | 1 / 3 / 1 |

비어서 돌아온 구간은 5.0초와 2.4초 길이의 두 곳이고 앞쪽은 11.349초가 걸렸다. 다른 1.4초 구간은 문장 뒷부분이 빠졌고, 깨진 문자가 한 곳 나왔다. 응답에 오류가 없어 워커는 실패로 세지 않았고 다시 보내지도 않았다. 원인은 찾지 못했다. 서버가 꺼져 있어 다시 재지 않았다.

추출 항목의 차이는 두 갈래다. 빈 구간에 있던 기한 하나가 항목에서 빠졌다. 다른 항목 하나는 근거 발화가 두 전사에 똑같이 있는데도 나오지 않았다. 전사가 달라져 판단 입력이 바뀐 영향으로 보이지만 추출을 같은 입력으로 다시 돌려 보지 않아 전사 때문인지 추출의 편차인지 가리지 못했다. 자동 항목 1개의 출처도 같은 이유로 단정하지 않는다.

복제한 회의는 실제 회의처럼 처리됐다. BE 회의와 승인 대기 4건이 생겼고, 자동 항목은 실제 태스크가 되어 Notion 까지 동기화됐다. 회의, 발화, 추출 항목, 승인 대기, 복제 파일은 지웠다. BE 에 회의 삭제 API 가 없어 DB 에서 트랜잭션으로 지웠고 원본 회의의 행 수가 그대로인 것을 확인했다. 지운 행과 전사 원자료는 레포 밖 `mm/eval-runs/393-gpu-stt-fallback/2026-11-07-rehearsal/` 에 있다. 이 글을 쓰는 시점에 자동으로 만들어진 태스크 1건과 Notion 페이지는 남아 있다. 복제가 같은 음성 파일 이름을 쓴 탓에 원본 회의의 트랙별 중간 전사 파일이 덮어써졌다. 원본의 합친 전사와 추출 결과는 그대로다.

서버를 켠 시간은 약 14분이고 비용은 계산값 약 ₩210 이다. 추출은 Terra 6회, Luna 6회를 불렀고 다른 측정의 1회 값으로 약 ₩220 을 장부에 추정으로 적었다. 장부 합은 예약 기준 ₩5,828 이고 PR 당 기준을 넘었다.

## 다음

GPU 서버의 빈 응답 원인을 찾기 전에는 전환 중 처리한 회의의 전사를 사람이 확인한다. 같은 음성을 다시 보내 재현되는지부터 본다.

재처리 경로는 아직 돌리지 않았다. 포기된 `stt` 회의가 없었고 재처리 시간도 재지 못했다. 긴 회의를 워커로 처리한 값도 없어 #393 은 열어 둔다.
