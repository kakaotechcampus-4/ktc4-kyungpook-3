# 리마인드 DM 을 웹 답장 안내로 바꾸다

- 날짜: 2026-11-07
- 이슈: #515
- PR: #524
- 브랜치: feature/515-reminder-web-reply
- 작성자: 김동우

## 한 일

- `messages._dm_body`: 봇이 가져가는 `body` 를 워크스페이스 이름, 답장을 기다리는 리마인드 수, 대화 링크로 만든다. 저장된 메시지 본문은 그대로다.
- `messages._reply_guide`: 첫 줄 아래 안내. 웹 계정이 없는 팀원은 대화 링크 대신 초대 요청 문구와 가입 링크를 받는다.
- claim 응답에 `web_url`, 대화 응답에 `web_reply_available` 을 더했다.
- `ai/capture/dm.py`: 답장 큐, DM 기록 메우기, 메우기 대상 기록을 지웠다. DM 창 글은 BE 로 넘기지 않고 웹 안내를 돌려준다. 같은 사람에게 1시간에 한 번이고 전송이 실패하면 세지 않는다.
- 두 계약 문서의 리마인드 DM 설명과 `backend/.env.example` 의 `APP_BASE_URL` 설명을 고쳤다.

## 왜

디스코드 DM 에는 서버 정보가 없어 여러 워크스페이스 팀원의 답장은 어느 대화의 것인지 추측해야 했다. 자세한 근거는 [결정 0048](2026-11-07-0048-reminder-web-reply-notice.md).

리뷰에서 고친 것은 셋이다. 막힌 시계는 태스크가 끝나거나 풀려도 열려 있어 수가 줄지 않았고, 시계 쪽만 태스크 상태로 거르게 했다. 전송에 실패한 안내가 1시간을 소진하던 것을 고쳤다. 계약 §5.7 에 남은 옛 설명을 고쳤다.
