# ground_truth/

- `speaker1_script.txt`, `speaker2_script.txt` — **정독(시나리오 A, 2인)용 예시 스크립트**. 각자 이 문장을 그대로 읽으면 정답이 100% 확보됩니다. 내용은 자유롭게 바꿔도 되지만(뉴스 기사 한 단락 등), 읽은 문장과 파일 내용이 **정확히** 일치해야 합니다. 1~2분 분량(약 300~500자) 권장.
- `meeting5_script.md` + `meeting5_A.txt`~`meeting5_E.txt` — **5인 정독 스크립트**. 화자 수를 2명에서 5명으로 늘렸을 때 정확도·화자 분리가 버티는지 보기 위한 것. 스탠드업 회의 형식으로 숫자·영문 약어·필러·의도된 끼어들기(크로스토크 테스트용)를 섞어 뒀습니다. 진행 순서와 녹음 방법은 `meeting5_script.md` 참고.
- 대화(시나리오 B, 정답 없이 자연 발화)는 녹음 후 화자별 wav 를 직접 들으며 `conv_speaker1.txt` 처럼 수기로 작성합니다.
- `eval_config.json` — `python eval.py --init` 으로 생성. 화자(user_id 또는 표시 이름) → 정답 파일, 세션별 시나리오, 크로스토크 체크 결과를 채웁니다.

- `extract5_script.md` + `extract5_A.txt`~`extract5_E.txt` — **Phase 1(추출/담당자 매칭) 골든셋 겸용 5인 정독 스크립트**. STT 검증은 동일하게 되고, 문장 내용 자체가 할일·담당자·마감일·잡담을 의도적으로 섞어서 짜여 있습니다. 대응하는 골든셋 기대값은 `extract/golden_set/case_01.json`~`case_11.json` 참고.

정답 파일 작성 팁
- **정독/스크립트 낭독**(speaker1/2, meeting5 등): 스크립트에 적힌 표기가 곧 정답입니다. 숫자·영문 약어는 스크립트에 쓰인 대로(예: `24시간`, `GPU`) 그대로 소리 내어 읽게 하세요. 미리 표기를 정해 두면 정답이 자동으로 확보됩니다.
- **자연 대화(사후 수기 작성)**: 반대로, 실제로 입 밖으로 나온 말을 기준으로 적으세요. 더듬거나 고쳐 말한 것도 들리는 대로 남기고, 지칭 대명사("그거", "저기")도 그대로 둡니다. 다만 숫자·영문 약어 표기는 일관되게(아라비아 숫자 + 영문 대문자) 고정해서, 읽은 방식이 아니라 표기 관례 차이 때문에 오류로 잡히는 걸 줄이세요.
- 웃음·기침 등은 정답에서 뺍니다. 문장부호는 있어도 무방합니다 — `eval.py` 가 정규화 WER/CER 을 함께 계산합니다.
