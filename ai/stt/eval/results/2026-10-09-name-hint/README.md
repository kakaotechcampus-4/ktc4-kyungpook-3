# Elice 이름 힌트 측정 (2026-10-09)

#195 의 결과다. Elice 전사에 팀 멤버의 부르는 이름을 프롬프트로 실으면 이름이 맞게 적히는지, 다른 문장이 나빠지지 않는지 쟀다. 결정은 [0020](../../../../docs/basis_for_decision/member/2026-10-09-0020-name-hint-prompt.md) 이다.

## 조건

- 서버: 팀 서버(t3.medium)의 측정용 사본, 커밋 9187a63
- 전사: Elice 새 주소(vLLM 0.19.1, openai/whisper-large-v3), 묶음 설정(운영과 같음), 회의당 동시 호출 6
- 프롬프트: `동우님, 재환님, 원준님, 지민님, 환님, 진호님.`
- 자료: 9/29 실녹음(한 사람 낭독, 대본 있음, 이름 자리 4), 6인 정렬본 m01·m02(시간축 합성, 정답에 이름 언급 없음), 10/2 2인 실녹음(정답 대본 없음, 이름 자리 2 를 손으로 정답)

6인의 숫자 셋은 숫자를 한글로 쓰는 쪽("5명" → "다섯 명")으로 바뀐 것이고, 정답이 마침 한글로 적혀 있어 CER 이 줄었다. 숫자·영문 표기를 맞추는 정규화 함수는 만들지 않았다. 대신 표기만 바뀐 자리(m01 의 "5명", "3가지", "wer", m02 의 "3가지")를 이름 힌트 전사에서 힌트 없음 표기로 되돌리고, `stt.eval.golden.session_metrics` 와 같은 식(화자별 공백 무시 CER, 정답 글자 수 가중)으로 다시 셌다. m02 의 차이는 전부 이 한 자리에서 나왔다. m01 은 되돌려도 5.73% 로 나은데, 힌트 없음이 놓친 첫 문장("다시 하겠습니다.")을 되살린 몫이다.
