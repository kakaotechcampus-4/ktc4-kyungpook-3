# 심사위원 시연 대본 — 이전 회의 용어로 전사 오류 잡기

## 상황

정기 회의입니다. 심사위원1 은 지민(PM), 심사위원2 는 동우를 맡습니다.
이 워크스페이스는 앞선 다섯 번의 회의에서 제브·폴러·루나 같은 팀 용어가 이미 쌓여 있습니다.
오늘 회의에서 동우가 "폴러" 라고 말한 줄이 음성 인식에서 "볼러" 처럼 잘못 받아 적히면, 시스템이 이 말을 확인합니다.

## 진행 방법

- 디스코드: 두 사람이 음성 채널에 들어가 `/join` → `/record` → 아래 표를 위에서부터 한 줄씩 번갈아 읽기 → `/stop`.
- 오프라인: 같은 표를 읽으며 녹음한 뒤 그 파일을 업로드합니다.
- 읽을 때는 표의 글을 바꾸지 말고, 또박또박 평소 속도로 읽습니다. 줄 번호와 화자 열은 읽지 않습니다.

## 기대 결과

- "채팅 폴러 서버 설정" 줄(6번): 담당·마감이 분명하고 "폴러" 가 팀 용어로 알려져 있어 **반영(auto)될 것으로 예상**합니다. 실제 게이트는 그날 워크스페이스 상태(비슷한 태스크, 임베딩)에 따라 확인 필요가 될 수도 있습니다.
- "발표 자료 최종본" 줄(8번): 마감이 "다음 주 중" 이라 애매해서 확인 필요로 갑니다.
- 폴러가 "볼러" 등으로 잘못 받아 적히면 6번 줄도 확인 필요로 가고, "폴러" 가 맞는지 묻는 후보가 함께 보입니다.
- 4번 줄은 완료 보고지만, 실제 실행(2026-11-10)에서 새 할 일로 잡혀 확인 카드가 하나 더 보였습니다. 이 카드는 PM 이 반려하면 됩니다.
