# 0014. 운영 Cog 는 RecordingCog 하나로 두고, 실시간 경로는 지우지 않고 비교와 회귀용으로 남긴다

- 날짜: 2026-09-26
- 상태: 결정됨. 0006 의 "다시 볼 조건" 에 적은 계획(멘토가 한쪽을 고르면 나머지를 지운다)을 바꾼다

## 배경

0006 은 녹음기 두 구현을 한 브랜치에 나란히 두고, 멘토가 고르면 나머지를 지우기로 했다. 9/16 에 캡처를
`/record` 하나로 합치고 종료 뒤 배치 전사(0008)로 갔다. `/live` 계열은 `capture/realtime/` 에 남겨
프로세스에 올리지 않았고, 폴더 설명에는 "팀이 정하면 폴더째 지운다" 고 적었다.

멘토는 #45 1차 리뷰(9/16) 본문 8과 고민 7에서 비교 실행과 회귀 근거로 남기는 것은 괜찮고 삭제 자체가
목표일 필요는 없다고 답했다. 대신 운영 Cog 를 하나로 고정하고, 과거 경로의 의존성과 유지 범위를
적으라고 했다. 녹음 키 갱신처럼 두 경로에 다 필요한 안전 처리가 실시간 폴더에만 있으면 새 경로가
퇴행하니 공용 계층으로 먼저 옮기라는 조건도 붙였다.

9/26 에 확인해 보니 키 갱신은 #57 이 `capture/voice_client.py` 로 옮겼는데 실시간 Cog 의 리스너가 남아
두 곳이 같은 갱신을 하고 있었다. 비교 도구 `stt/realtime/bench.py` 는 테스트 재구성(8d562b2) 뒤로
import 가 깨져 돌지 않았다. 둘 다 이번에 고쳤다 (`ai/docs/2026-09-26-shared-receive.md`).

## 검토한 선택지

- 폴더를 지운다. 유지할 코드가 줄고 운영 경로만 남는다. 대신 0003~0006 의 실측을 다시 낼 코드가
  사라지고, 회의 중 전사와 배치를 같은 녹음으로 나란히 재는 일(0006 에 남은 일)을 할 수 없다. 공용 수신
  계층을 발화 단위 흐름으로 한 번 더 지나는 테스트(`tests/capture/realtime/`)도 같이 사라진다.
- 지금처럼 두되 범위를 적지 않는다. 당장 드는 일은 없다. 그런데 "폐기했다" 와 "남겨 둔다" 가 같이 적힌
  상태에서 누가 무엇을 지켜야 하는지가 비어 있었고, 위의 중복 리스너와 깨진 벤치가 그 사이에 생겼다.
- 남기고 운영 경로와의 경계와 유지 범위를 정한다. 이것을 골랐다.

## 결정

운영 Cog 는 `capture/discord_adapter.py` 의 RecordingCog 하나다. 운영 봇(지금은 `capture/run_recorder.py`)은
이것만 붙이고 `capture/realtime/` 과 `stt/realtime/` 의 모듈을 하나도 싣지 않는다.
`tests/capture/test_operating_boundary.py` 가 둘 다 본다. 그래서 지우기로 하면 폴더째 지울 수 있다.

실시간 경로는 새 기능을 받지 않는다. 공용 수신 계층(`capture/voice_client.py`, `streaming_sink.py`,
`track_writer.py`, `audio.py`, `timeline.py`)을 바꾸는 변경은 실시간 테스트까지 녹색이어야 하고, 벤치의
무과금 실행이 돌아야 한다(`tests/stt/realtime/test_bench.py`). 두 경로에 다 필요한 처리는 공용 계층에만
둔다. 두 Cog 에 같은 모양으로 남은 것(`is_recording`, `required_intents`, 녹음 종료 콜백 예약, 종료 때의
드레인)도 같은 원칙으로 옮긴다. 배치 쪽 파일을 다른 작업이 고치는 중이라 그 이동은 다음 PR 이다.
의존성 목록과 실행 명령은 `capture/realtime/__init__.py` 에 적었다.

## 다시 볼 조건

- 비교 실행 없이 실시간 폴더만 공용 계층에 맞춰 고치는 일이 쌓이면 지운다. 유지 비용이 비교 가치보다
  커졌다는 뜻이다.
- 0006 에 남은 비교(같은 오디오로 두 방식의 지연, 비용, 서버 부하)를 끝냈고 회의 중 전사를 다시 들이지
  않기로 하면 지운다.

지울 때는 `capture/realtime/`, `stt/realtime/`, `tests/capture/realtime/`, `tests/stt/realtime/` 을 통째로
지우고, 0003~0006 이 코드 대신 커밋 해시를 가리키게 고친다.
