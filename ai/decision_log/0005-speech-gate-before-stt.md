# 0005. 전사 앞에 말 필터를 하나 더 둔다

- 날짜: 2026-09-12
- 상태: 결정됨

## 배경

배경음악의 희미한 보컬이 에너지 VAD 를 통과해 전사까지 갔고, 위스퍼가 아무도 하지 않은 문장을 냈습니다.

```
자막 제공 및 자막 제공 및 광고를 포함하고 있습니다
매주 일요일 업로드됩니다
다음 영상에서 만나요!
```

이 줄은 회의록에 실제 팀원의 발언으로 남고, 그 회의록을 다음 단계의 할일 추출이 그대로 받습니다. 지어낸
문장 하나가 지어낸 할일 하나가 되어 사람에게 배정됩니다. 줄이 빠지는 것보다 나쁩니다.

지금의 에너지 VAD 로는 가를 수 없습니다. 음악이 작게 말하는 사람과 같은 진폭에 있기 때문입니다.
디스코드의 잡음 억제도 사람 목소리는 일부러 남기고, 노래도 목소리입니다.

## 검토한 선택지

- 에너지 임계를 올린다: 새로 붙일 것이 없다 / 작게 말하는 사람이 같이 잘린다. 진폭은 둘을 가르는 축이 아니다.
- 전사한 뒤 문구 목록으로 거른다: 싸다 / 목록에 없는 새 환각은 그대로 나가고, 유료 호출은 이미 나간 뒤다.
- 실로 VAD 를 전사 앞에 세운다: 판정 축이 진폭이 아니라 말이냐 아니냐다 / 모델을 하나 올려야 한다.

## 결정

실로 VAD 를 threshold 0.95 로 돌려 말 비율이 0.60 이상인 발화만 전사합니다.

이 프로젝트 오디오에서 잰 값입니다.

| | 말 비율 (threshold 0.95) |
|---|---|
| 골든셋 실제 발화 18건 | 최소 75%, 5퍼센타일 83%, 중앙값 97% |
| 환각을 만든 클립 3건 | 42%, 0%, 33% |
| 숨소리 1건 | 0% |

42% 와 75% 사이에 아무것도 없어서 그 가운데인 0.60 에 자릅니다.

비용은 워밍업 뒤 RTF 0.00139, 코어 하나의 0.14% 입니다. 첫 호출은 모델을 올리느라 432ms 가 걸리므로
처음 쓸 때 한 번만 올리고 워커들이 같은 인스턴스를 나눠 씁니다. 새 의존성은 없습니다. faster-whisper 가
이미 requirements.txt 에 있고, `faster_whisper.vad.get_speech_timestamps` 는 위스퍼를 올리지 않고
VAD 만 돌립니다.

VadOptions 에는 threshold 말고 `min_speech_duration_ms=0`, `speech_pad_ms=0` 을 같이 줍니다. 패딩과
최소 길이가 붙으면 비율 자체가 달라져서 위 수치가 의미를 잃습니다.

자리는 워커가 API 를 부르기 직전입니다 (`stt/session.py`). 수신 스레드는 20ms 안에 돌아와야 하므로
거기에 ONNX 추론을 넣을 수 없습니다. 거른 발화는 전사되지 않고 회의록에도 올라가지 않습니다. 대신
종료 요약에 몇 건을 걸렀는지 적고, 발화마다 길이와 말 비율을 로그에 남깁니다.

판정이 예외를 내면 그 발화는 그대로 전사로 보내고 실패만 셉니다. 고장 난 필터가 회의록을 지우는 쪽이
환각 한 줄보다 나쁩니다.

## 재지 않은 것

- 골든셋은 낭독이라 "네", "맞아요" 같은 짧은 대답과 맞장구가 18건 안에 없습니다. 게이트가 그런 발화를
  남기는지는 아직 모릅니다.
- 환각 표본은 세 건뿐이고, 전부 한 세션에서 배경음악 한 곳을 두고 나왔습니다.
- 골든 트랙은 파일 오디오라 디스코드의 잡음 억제를 거치지 않았습니다. 실제 통화를 지난 소리가 같은
  비율로 나오는지는 확인하지 않았습니다.
- 거른 발화도 턴 배정과 `note_post` 는 이미 받은 뒤입니다 (`stt/session.py` 의 `_assign_locked`).
  전사되지 않은 발화가 턴 경계에 영향을 줍니다. 실제 회의에서 이게 얼마나 보이는지는 보지 않았습니다.

## 다시 볼 조건

- 실제 회의에서 짧은 대답이 사라진다는 말이 나오면 임계를 다시 잡습니다. 거름 로그에 발화 길이와 말
  비율이 남으므로 오디오를 보관하지 않고도 다시 잡을 수 있습니다.
- 환각 표본이 다른 배경음에서도 모이면 42%와 75% 사이가 그대로 비어 있는지 다시 봅니다.
- 끄는 법은 `stt/speech_gate.py` 의 `ENABLED = False` 한 줄입니다. "왜 내 말이 안 나왔냐"는 물음이
  들어왔을 때 필터를 빼고 같은 회의를 다시 돌릴 수 있어야 합니다.
