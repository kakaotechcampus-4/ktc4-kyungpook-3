# 자주 묻는 질문

자주 생기는 문제와 해결 방법이에요. 문제가 생긴 곳(Discord, 업로드, 회의록, 메시지, 계정)별로 나눴어요.

## Discord

### 봇 명령(`/join`, `/record`)이 안 보여요

- 봇이 그 서버에 들어와 있는지 확인해요. **설정 > 연결**에서 **연결됨**으로 보여도 봇이 서버에서 빠졌을 수 있어요. 서버 멤버 목록에서 봇이 있는지 보고, 없으면 다시 연결해요.
- 봇을 막 추가했다면 Discord 앱을 새로 고치거나 잠시 기다려요. 슬래시 명령이 뜨는 데 시간이 걸릴 수 있어요 `[확인 필요: 명령 등록 지연 실제 시간]`.
- 채널 권한에서 봇이나 내 역할의 **애플리케이션 명령 사용**이 막혀 있지 않은지 봐요 `[확인 필요]`.

### `/record`를 쳤는데 녹음을 안 해요

| 봇 답 | 해결 |
|---|---|
| 봇이 음성채널에 없습니다. `/join` 먼저 실행해 주세요. | 음성 채널에 들어간 뒤 `/join` → `/record` |
| 먼저 음성채널에 들어간 뒤 다시 실행해 주세요. | `/join`을 친 사람이 음성 채널에 있어야 해요 |
| ⚠️ 이 디스코드 서버가 웹 워크스페이스에 연결돼 있지 않아… | PM이 웹에서 Discord 연결을 마쳐요 |
| 이미 녹음 중입니다. `/stop` 으로 먼저 종료하세요. | 서버마다 한 번에 하나만 녹음해요 |
| ⏳ 새 버전을 배포하느라 봇이 곧 다시 시작됩니다. | 1분쯤 뒤 다시 `/record` |

녹음 중 봇이 다시 시작되면 "⚠️ 봇이 다시 시작되어 끊긴 회의의 녹음된 부분을 처리합니다."가 떠요. 녹음된 부분은 처리돼요. 이어서 기록하려면 `/join` → `/record`를 다시 해요.

### 팀원 연결 목록에 사람이 없어요

- 목록은 **봇이 들어간 Discord 서버의 사용자**예요. 그 사람이 서버에 들어와 있는지 확인해요.
- 연결 뒤에 서버에 들어온 사람은 **팀** 화면의 **연결되지 않은 계정**에서 이어요.
- "디스코드 서버에서 팀원을 찾지 못했어요."가 뜨면 서버에 봇 말고 사람이 없거나 봇이 목록을 못 읽은 거예요 `[확인 필요: 봇의 Server Members Intent 설정 필요 여부]`.
- "Discord를 연결하지 않아 팀원을 불러올 수 없어요."가 뜨면 Discord 연결부터 해요.

### 회의 채팅이 안 들어와요

- **설정 > 연결 > 회의 채팅 채널**에 채널이 골라져 있는지 확인해요.
- 수집은 **매일 09:00 (한국 시간)**에 한 번이에요. 오늘 쓴 메시지는 다음 날 아침에 들어와요.
- 저장할 때 "봇이 이 채널을 읽을 수 없어요"가 떴다면 Discord 채널 권한에 봇을 추가해요.
- 채팅에서 나온 일은 자동 반영되지 않고 PM **확인 필요**로 가요. 태스크 목록에 바로 안 보이는 게 정상이에요.

## 업로드

### 업로드가 실패해요 (413, 파일이 너무 큼)

- 서버 기본 한도는 **100MB**예요. 화면에는 200 MiB로 보이지만 100MB를 넘으면 서버가 거절해요 `[확인 필요: 운영 한도]`.
- 길이는 2시간 이하예요.
- 줄이는 법: wav 대신 mp3·m4a로 바꾸거나, 모노·낮은 비트레이트로 다시 저장하거나, 회의를 나눠 올려요.

### "MP3·WAV·M4A·OGG·WebM 파일만 올릴 수 있어요."

확장자가 mp3·wav·m4a·ogg·webm 중 하나여야 해요. 다른 형식은 변환해서 올려요.

### 회의 올리기를 누르면 처리 화면으로 가요

이미 정리 중인 회의가 있어요. 워크스페이스마다 한 번에 하나씩 정리해요. 끝난 뒤 올려요.

### "올린 결과를 확인하지 못했어요"

네트워크가 끊겨 서버가 받았는지 모르는 상태예요. 다시 올리기 전에 **회의록** 목록에 그 회의가 있는지 먼저 봐요. 두 번 올리면 회의가 둘 생길 수 있어요.

### 회의 올리기 버튼이 없어요

업로드는 PM만 할 수 있어요.

## 처리

### 처리가 오래 걸려요

- 처리 화면의 단계를 봐요. **차례를 기다리고 있어요**면 앞 회의가 끝나기를 기다리는 중이에요.
- 업로드 회의는 **화자 지정을 기다리고 있어요**에서 멈춰 있을 수 있어요. PM이 화자를 지정해야 이어져요(7일 안).
- 전사와 판단은 외부 AI 서비스를 써서 회의 길이에 따라 시간이 걸려요 `[확인 필요: 1시간 회의 기준 평균 처리 시간]`.
- Discord 회의는 채널에 "⚠️ … 자동 재시도" 메시지가 오면 실패한 단계를 다시 시도하는 중이에요. "자동 재시도를 멈췄습니다"가 뜨면 운영자에게 알려요.

### "화자 지정 기한 만료"

업로드 뒤 7일 안에 화자를 지정하지 않았어요. 파일을 다시 올려요.

## 회의록과 승인

### 할 일이 담당자 없이 "보류"로 가요

회의에서 누군가를 담당자로 말했는데 누구인지 못 찾았어요.

- 팀원 연결에서 이름을 실제로 부르는 이름과 같게 적었는지 확인해요.
- 회의에서 별명·줄임말로 부른다면 **팀** 화면에서 그 팀원에 **별칭**을 더해요.
- Discord 사용자가 팀원과 연결돼 있지 않으면 화자 이름을 몰라요. **연결되지 않은 계정**을 이어요.
- 지금 보류된 항목은 **채워 넣기**로 담당자를 골라 승인해요.

### 할 일이 너무 적거나 다 "확인 필요"로 가요

- 조건을 모두 만족한 일만 자동으로 반영돼요. 같은 회의에서는 보통 첫 항목만 그렇게 돼요. "누가 해 주면 좋겠다"처럼 담당자를 가리키는데 애매하면 확인 필요로 가요.
- 기존 태스크를 바꾸자는 말과 채팅 회의에서 나온 일은 항상 확인 필요예요.

### 승인했는데 "보신 뒤에 내용이 바뀌었어요"가 떠요

화면을 연 사이 다른 PM이나 AI가 값을 바꿨어요. 비교표를 보고 맞으면 **새 내용을 확인했어요, 승인**을 눌러요. → [충돌 안내](review-approve.md#충돌-안내-다른-사람이-먼저-바꿨을-때)

### 일반 팀원에게 "확인 필요"가 안 보여요

정상이에요. 확인 필요·보류는 PM만 봐요.

### Notion에 안 올라가요

- Notion 연결은 선택이에요. **설정 > 연결**에서 연결됐는지 봐요.
- 확인 필요 항목은 승인한 뒤에 올라가요.
- 승인 화면의 Notion 상태가 **반영 실패**면 다시 요청해요. 데이터베이스 속성을 바꿨다면 **속성 다시 맞추기**를 눌러요.

## 메시지

### 팀원이 DM을 못 받아요

- 메시지 화면에 **Discord 미연결 · DM 이 나가지 않아요**가 보이면 Discord 연결부터 해요.
- **DM 못 보냄** / "서버 DM이 막혀 있어요"면 팀원이 Discord 개인정보 설정에서 서버 멤버 DM을 막은 거예요. 허용해 달라고 해요.
- 팀원이 Discord 계정과 연결돼 있지 않으면 보낼 수 없어요. 팀원 연결을 확인해요.
- 재촉은 PM이 **이대로 발송**을 눌러야 나가요(재촉 자동 승인을 켜지 않았다면).

### 팀원이 DM에 답장했는데 안 보여요

봇 DM 창에 쓴 글은 전달되지 않아요. DM 속 링크를 열어 웹 대화에서 답장하도록 안내해요.

## 계정

### 인증 코드 메일이 안 와요

스팸함을 확인해요. 코드는 10분 동안 쓸 수 있어요. 다시 보내기는 60초 뒤에 할 수 있어요.

### 받은 초대가 안 보여요

PM이 적은 이메일과 로그인한 이메일이 같아야 해요. 초대 메일은 가지 않으니 PM에게 어떤 이메일로 초대했는지 물어요.

### 로그인이 막혔어요

여러 번 틀리면 잠시 막혀요. **비밀번호를 잊으셨나요?**에서 재설정하거나 잠시 뒤 다시 해요.

### 탈퇴하고 싶어요

계정 탈퇴 화면(`/account/withdrawal`)에서 탈퇴할 수 있어요 `[확인 필요: 설정 > 내 계정에서 들어가는 버튼 위치와 PM 탈퇴 조건]`. 계정과 로그인 세션은 지워지고, 팀의 공동 기록에는 "탈퇴한 사용자"로 남아요.
