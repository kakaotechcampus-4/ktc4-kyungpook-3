# 팀원 가이드

PM이 아닌 팀원이 알아야 할 것만 모았어요. 팀원은 Discord에서 회의하고, 마감 전에 DM 안내를 받고, 웹에서 답장하면 돼요.

## 팀원이 하는 일 한눈에

| 언제 | 할 일 | 어디서 |
|---|---|---|
| 처음 한 번 | 초대 수락 | 웹 시작 화면 |
| 회의 때 | 음성 채널에서 회의 (녹음 안내 확인) | Discord |
| DM을 받으면 | 링크를 열고 진행 상황 답장 | Discord → 웹 |
| 아무 때나 | 내 태스크·회의록 보기 | 웹 |

## 1. 초대 수락하기

PM이 팀 화면에서 내 **아이디**로 찾아 초대를 만들어요. **알림은 가지 않아요.** PM이 Discord 등으로 알려 줘요.

1. 먼저 가입하고 가입할 때 정한 아이디를 PM에게 알려 줘요. 초대를 받으면 로그인해요. 가입 방법은 [시작하기](getting-started.md#1-가입과-로그인)에 있어요.
2. **어떻게 시작할까요?**에서 **팀원으로 시작**을 눌러요.
3. **받은 초대**에 워크스페이스 이름, 내 팀원 이름, 초대한 사람이 보여요.
4. **수락**을 누르면 바로 들어가요.

- 초대가 안 보이면 PM이 찾은 아이디가 내 아이디와 같은지 확인해요. 초대도 소속도 없으면 "PM에게 가입한 아이디를 알려 주고 초대를 요청하세요."가 보여요.
- **거절**하면 그 초대로는 다시 들어갈 수 없어요. PM에게 새 초대를 요청해야 해요.
- "이 초대는 더 이상 수락할 수 없어요. PM에게 문의하세요."가 뜨면 PM이 초대를 취소했거나 이미 처리된 초대예요.
- 워크스페이스 설정이 끝나기 전이면 "PM이 이 워크스페이스 설정을 마무리하고 있어요"가 보여요. 기다리면 돼요.

> 📷 **사진 자리**: 팀원으로 시작 화면의 받은 초대 (파일: ../assets/user-member-invitation.png)

## 2. 회의할 때

- PM이나 다른 팀원이 `/record`를 치면 채널에 "🔴 녹음·전사 중입니다."가 올라와요. 음성은 화자별로 녹음되고 외부 서비스(Elice)로 보내 글로 옮겨요.
- 녹음을 원하지 않으면 음성 채널에서 나가요.
- 회의에서 "제가 목요일까지 할게요"처럼 **누가·언제까지**를 분명히 말하면 조건에 따라 그대로 태스크가 될 수 있어요. 같은 회의에서는 보통 첫 항목만 그렇게 만들어지고, 애매하면 PM이 확인한 뒤 생겨요.

명령 사용법은 [회의 기록하기](record-meeting.md#1-discord-음성-채널에서-녹음하기)를 봐요.

## 3. DM을 받았을 때

마감이 다가오면 봇이 Discord DM을 보내요. 내용은 웹에 있고 DM에는 안내와 링크만 있어요.

```text
<워크스페이스>에서 답장을 기다리는 리마인드가 1개 있어요.
웹에서 답장해 주세요.
https://<서비스 주소>/...
```

1. 링크를 열어요. 로그인이 안 돼 있으면 로그인해요.
2. **메시지** 대화에서 리마인드 내용을 읽어요. 예: "'API 연동' 마감이 9월 18일 금요일이라 한번 여쭤봐요."
3. 아래 **PM에게 메시지** 칸에 진행 상황을 적고 보내요. `Enter` 보내기, `Shift+Enter` 줄 바꿈이에요.

**봇 DM 창에 답장하지 마세요.** 거기 쓴 글은 전달되지 않아요. 꼭 웹 대화에 써요.

웹 계정이 아직 없으면 DM에 "웹 답장을 하려면 가입한 뒤 PM 에게 아이디를 알려 초대를 받아 주세요."가 와요.

> 📷 **사진 자리**: 팀원 화면의 메시지 대화와 PM에게 메시지 입력칸 (파일: ../assets/user-member-reply.png)

## 4. 답장은 이렇게 쓰면 좋아요

AI가 답장을 읽고 태스크를 바꿔요. 바꾼 내용은 PM이 보고 되돌릴 수 있어요.

| 이렇게 쓰면 | 일어나는 일 |
|---|---|
| "다 끝났어요" | 태스크를 완료로 바꾸거나 PM에게 물어요 |
| "금요일까지 미뤄야 할 것 같아요" | 마감 변경을 PM에게 확인받아요 |
| "디자인이 안 나와서 막혀 있어요" | 태스크가 막힘으로 바뀌어요 |
| "지금 하고 있어요" | 진행 중으로 두고 기다림을 풀어요 |

`[확인 필요: 위 예시는 답장 판단의 대표 동작. 실제 결과는 AI 판단에 따라 바로 바뀌거나 PM 확인으로 갈 수 있음 — ../design/ai/reply-judgment.md 와 맞출 것]`

- 리마인드에 **72시간** 동안 답이 없으면 태스크가 자동으로 **막힘**이 돼요. 짧게라도 답해 주세요.
- 태스크가 여러 개면 어느 일인지 이름을 같이 적어 주세요.

## 5. 팀원이 볼 수 있는 것

| 화면 | 팀원 | PM과 다른 점 |
|---|---|---|
| 대시보드 | 볼 수 있어요 | 확인이 필요한 일, 되돌리기는 안 보여요 |
| 회의록 | 요약·전사문·반영된 일 | **확인 필요·보류 항목은 보이지 않아요** |
| 태스크 | 리스트·보드·캘린더·간트 | **확인 필요** 탭이 없어요. 상태·담당·마감은 바꿀 수 없어요(답장으로 알려요) |
| 메시지 | 내 대화만 | 보내기 전 확인이 없어요 |
| 팀 | 팀원 목록 | 초대·연결은 PM만 |
| 설정 | 읽기만 | 연결·알림을 바꿀 수 없어요 |
| 회의 올리기, 화자 지정, 확인 요청 | 못 해요 | PM만 |

> 📷 **사진 자리**: 팀원 계정으로 본 태스크 리스트 (확인 필요 탭 없음) (파일: ../assets/user-member-tasks.png)

## 6. 브라우저 알림 받기

메시지 대화 위에 알림을 켜자는 띠가 보이면 **알림 켜기**를 눌러요. 새 리마인드가 오면 이 기기로 바로 알려 줘요. iPhone·iPad는 Safari에서 홈 화면에 추가한 앱으로 열어야 해요.
