# 처음 쓰는 분을 위한 안내

앱의 **?** 버튼과 빈 화면의 **방법 보기**에 들어갈 원고예요. PM과 팀원이 같은 내용을 보고, 단계마다 팀원이 할 일을 한 줄로 덧붙였어요. 화면 구현은 FE 이슈에서 다뤄요.

> 회의는 웹이 아니라 **Discord 음성 채널**에서 기록해요. 웹은 정리된 결과를 보고 승인하는 곳이에요.

## 1. Discord 서버 준비

팀이 함께 쓸 Discord 서버가 없으면 하나 만들고, 팀원들을 서버에 초대해요.

1. Discord 왼쪽 서버 목록의 **+**를 눌러 **직접 만들기**를 골라요.
2. 서버 이름 옆 메뉴에서 **초대하기**를 눌러 초대 링크를 복사해요.
3. 링크를 팀원들에게 보내요.

자세한 방법은 Discord 도움말을 봐요: [서버 만들기](https://support.discord.com/hc/ko/articles/204849977) · [초대 링크](https://support.discord.com/hc/ko/articles/208866998)

*팀원은: 받은 링크로 서버에 들어와요. 서버에 들어와 있어야 3단계에서 PM이 연결할 수 있어요.*

## 2. 팀원 초대

1. **팀** 화면에서 팀원 줄의 **초대**를 눌러요.
2. 팀원이 **가입할 때 정한 아이디**로 찾아요. 이름과 아이디를 확인하고 초대해요.
3. **알림은 가지 않아요.** 초대한 뒤 Discord 등으로 직접 알려 주세요.

*팀원은: 먼저 가입하고, 가입할 때 정한 **아이디**를 PM에게 알려 줘요. 초대를 받으면 로그인 → **팀원으로 시작** → **받은 초대**에서 **수락**을 눌러요. 거절하면 그 초대로는 다시 들어갈 수 없어요.*

## 3. Discord 연결과 팀원 연결

1. **설정 > 연결**에서 Discord를 연결하고, 봇을 1단계의 서버에 추가해요.
2. 서버 사용자와 서비스 팀원을 짝지어요.

- 서버에 아직 들어오지 않은 사람은 목록에 보이지 않아요. 1단계부터 확인해요.
- 팀원 이름을 정확히 고르세요. 잘못 고르면 그 사람이 말한 할 일의 담당자를 찾지 못해요.

*팀원은: 할 일이 없어요. 서버에만 들어와 있으면 돼요.*

## 4. 회의 기록

1. Discord 음성 채널에 들어가요.
2. 채팅창에 `/join`을 입력해 봇을 부르고, `/record`로 녹음을 시작해요.
3. 회의가 끝나면 `/stop`을 입력해요.

- 음성 채널에 있는 사람이면 **누구나** 명령을 쓸 수 있어요.
- 녹음을 시작하면 채널에 녹음 안내가 올라가요.
- Discord 없이 만나서 회의했다면 녹음 파일을 웹에서 **업로드**해요(PM).

## 5. 결과 확인

몇 분 뒤 대시보드와 회의 화면에 정리된 결과가 보여요.

| 표시 | 뜻 |
|---|---|
| **반영된 것** | 승인 없이 태스크로 만든 일 |
| **확인 필요** | PM이 보고 승인해야 하는 일 |
| **보류** | 담당자를 찾지 못한 일. PM이 담당자를 골라 승인해요 |

*팀원은: 대시보드에서 내 할 일을 봐요. 마감이 다가오면 Discord **DM**으로 리마인드가 와요. 답장은 DM이 아니라 **웹의 메시지 화면**에서 해요. 서버 멤버의 DM을 막아 두었다면 리마인드를 받지 못할 수 있어요.*
