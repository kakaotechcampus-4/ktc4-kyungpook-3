# 추가 지표

AI 품질을 평가하려고 수집하거나 수집할 값을 정리한다. 지금 측정값이 있으면 날짜·조건과 함께 적고, 없으면 "운영에서 수집 예정"으로 둔다. 측정 조건이 다른 수치끼리 직접 비교하지 않는다.

## 지표를 읽는 법

- **certain 은 정답 확률이 아니다.** "근거 원문에 명시됐나"에 대한 Jev 판정이다. 태스크가 맞는지는 운영의 PM 승인·수정·반려로 따로 잰다([근거 검증](../design/ai/evidence-check.md)).
- **신뢰 상한을 함께 본다.** 0건이어도 표본이 작으면 실제 비율이 높을 수 있다. 할 일 부정 대사 83개, 마감 44개로는 0건이어도 상한이 약 4.4%·8% 아래로 내려가지 않는다.
- **반복은 표본이 아니다.** 같은 대사를 다시 물은 결과라 대사 단위로 센다.
- **합성 세트 수치는 실제 분포를 대표하지 않는다.** 오인식 검사의 합성 세트 93% 차단은 실제 STT 오류에서 14%였다(첫 구현 기준).
- **auto 되돌리기 비율은 하한값이다.** 버전 1이고 대기 중인 카드가 없는 태스크만 되돌릴 수 있어서, PM 이 고치거나 직접 지운 오생성은 들어가지 않는다. 생성한 주 기준으로 묶으므로 최근 주는 아직 되돌릴 시간이 지나지 않아 낮게 나온다.
- **삭제·탈퇴는 소급해서 빠진다.** 삭제한 회의와 탈퇴로 정리한 공간의 회의·항목은 KPI view 에서 과거 기간까지 사라진다. 삭제된 회의의 승인 카드도 이미 승인·반려된 것까지 함께 빠진다(회의 삭제가 카드 payload 를 지우기 때문이다). 심사용 시드(#621)는 시연용으로 일부러 넣은 데이터라 KPI 에 남긴다. 시드 회의는 시작 시각을 며칠 전으로 합성해 처리 시간이 며칠로 잡히므로, KPI 대시보드의 처리 시간 패널은 하루(86400초) 넘게 잡힌 회의를 뺀다.
- **`AUTO_CREATE_ENABLED` 가 꺼져 있으면 auto 는 0건이다.** 그 기간의 자동 반영률·되돌리기 비율은 비어 있는 것이 정상이다.
