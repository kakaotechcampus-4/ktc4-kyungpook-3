# 이용약관

> 2026-11-09 승인한 제품 정책을 반영한 게시 준비본입니다. [정책 확정 내용과 게시 상태](README.md)에 따라 남은 확인을 마친 뒤 게시 버전·시행일을 부여합니다.

- 제품 정책 확정일: 2026-11-09
- 기존 동의 API의 초안 식별값: 2026-11-08
- 공개 버전·시행일: 실제 서비스 게시 시 확정

현재 동의 API의 `2026-11-08`은 기존 초안 식별값입니다. 실제 게시 때 BE의 동의 버전과 FE의 본문·표시 버전을 함께 갱신합니다. 기존 테스트 동의 기록은 이번 본문에 대한 동의로 간주하지 않습니다.

## 제1조 목적

이 약관은 Manager's Manager(이하 "운영자")가 제공하는 Manager's Manager(이하 "서비스")의 이용 조건과 절차, 운영자와 이용자의 권리와 의무를 정합니다.

## 제2조 정의

- 이용자: 이 약관에 동의하고 가입한 사람
- 워크스페이스: 팀이 함께 쓰는 공간
- PM: 워크스페이스에서 승인과 팀원 관리를 맡는 이용자
- 콘텐츠: 이용자가 녹음하거나 올린 회의 음성, 전사, 회의록, 태스크, 메시지

## 제3조 약관의 효력과 변경

1. 이 약관은 서비스 화면에 게시하고, 이용자가 동의하면 효력이 생깁니다.
2. 운영자는 관련 법령을 어기지 않는 범위에서 약관을 바꿀 수 있습니다. 바꾸면 시행 7일 전에 서비스 화면으로 알리고 다시 동의를 받습니다.
3. 바뀐 약관에 동의하지 않으면 서비스 이용을 멈추고 탈퇴할 수 있습니다.

## 제4조 가입

현재 운영 범위는 팀원·멘토·심사위원 중심의 교육·평가용 시범 운영입니다. 가입·재동의 화면은 연결돼 있으나 문서 게시 설정은 준비 중입니다. 준비 화면을 최종 본문에 대한 동의로 취급하지 않습니다.

1. 이메일 또는 카카오 계정으로 가입하며, 이 약관과 개인정보처리방침을 확인하고 기본 두 문서에 동의합니다. 마케팅 수신 동의는 받지 않습니다. 별도 동의가 필요한 처리에는 해당 내용을 구분해 안내하고 동의를 받습니다.
2. 다른 사람의 정보로 가입하면 이용을 제한할 수 있습니다.

## 제5조 서비스 내용

1. 서비스는 회의 음성을 글로 옮기고, 할 일과 변경 사항을 찾아 회의록과 태스크 후보를 만듭니다.
2. 디스코드 봇으로 회의를 녹음하거나, PM이 웹에서 녹음 파일을 올릴 수 있습니다. 일반 팀원의 웹 업로드와 별도 원본 듣기는 이번 배포 범위에 없습니다.
3. 이용자가 연결한 Notion 에 태스크를 반영하고, 팀원에게 리마인드 메시지를 보냅니다.
4. 회의 정리를 위해 음성·전사·관련 태스크와 메시지 문맥을 외부 서비스로 보냅니다. 업체별 항목·목적·보관과 공식 정책 링크는 [개인정보처리방침 5항](privacy.md#5-처리-위탁과-국외-이전)에 안내합니다. 업체 정책 링크만으로 필요한 고지·동의를 대신하지 않습니다.

## 제6조 자동 정리 결과

1. 전사, 할 일, 담당자, 마감일은 자동으로 만든 결과라 틀릴 수 있습니다.
2. 확실하지 않은 항목은 PM 의 확인을 거치며, 이용자는 반영된 내용을 확인하고 고칠 책임이 있습니다.

## 제7조 이용자의 의무

1. 회의를 녹음하거나 녹음 파일을 올리는 이용자는 참석자에게 녹음 사실과 외부 서비스로 보낸다는 사실을 미리 알리고, 관련 법령이 요구하는 동의를 받아야 합니다.
2. 이용자는 녹음하거나 올릴 권한이 있는 회의만 서비스에 넣어야 합니다.
3. 이용자는 계정을 다른 사람에게 빌려주거나 넘기면 안 됩니다.

## 제8조 금지 행위

- 참석자 몰래 녹음한 회의를 넣는 행위
- 다른 사람의 정보를 도용하는 행위
- 서비스 운영을 방해하거나, 허락 없이 시스템에 접근하는 행위
- 법령이나 공공질서에 어긋나는 내용을 넣는 행위

## 제9조 콘텐츠

1. 콘텐츠의 권리는 이용자와 워크스페이스에 있습니다.
2. 운영자는 콘텐츠를 서비스 제공에만 쓰며, 인공지능 학습과 모델 개선에 쓰지 않습니다. 외부 업체의 학습 이용·보관 조건은 개인정보처리방침의 업체별 안내와 구분합니다.
3. 성공 인계한 회의의 원본·파생 음성을 삭제합니다. 관련 자동 정리 변경은 병합돼 있습니다. 구체적인 보관 기준과 외부 업체 사본의 범위는 [개인정보처리방침 3항](privacy.md#3-보유-기간과-파기)을 따릅니다. 이번 문서 작업에서 운영 파일 삭제를 실행한 것은 아닙니다.
4. 전사·회의록은 별도 자동 만료기간 없이 회의나 워크스페이스가 삭제될 때까지 보관합니다. 회의 삭제가 활성화되면 전사·회의록·추출·근거를 지우고 이미 만든 태스크는 유지하며 원본 삭제 상태를 표시합니다. 여러 회의가 합쳐진 승인 대기 카드는 삭제 회의의 기여만 제거하고 나머지 내용으로 다시 구성합니다. 회의 삭제는 현재 기본 비활성이며 [운영 활성화 절차](../../deploy/README.md)가 필요합니다.

## 제10조 서비스 변경과 중단

운영자는 점검, 장애, 외부 서비스 중단 때 서비스를 멈출 수 있으며, 미리 알릴 수 있으면 알립니다.

## 제11조 탈퇴와 이용 제한

1. 이용자는 계정 메뉴의 탈퇴 화면에서 전체 소속 공간과 삭제 범위를 확인한 뒤 탈퇴를 요청합니다. 마지막 PM은 로그인 가능한 다른 팀원에게 PM 권한을 넘겨야 합니다. 다른 활성 팀원이 있는데 넘길 사람이 없으면 탈퇴를 거절합니다. 유일한 활성 멤버인 공간에서는 권한 이전 없이 공간과 회의·태스크·메시지도 함께 삭제합니다. 활성 Discord 전용 팀원도 단독 여부에 포함합니다.
2. 탈퇴 접수 때 계정·로그인 세션과 본인의 연결 정보·팀원 프로필·별칭을 삭제합니다. 다른 구성원이 남은 공동 회의·태스크·메시지는 보존하고 작성자를 `탈퇴한 사용자`로 표시합니다. 공동 기록의 자유 본문·음성 전체 자동 익명화나 이미 외부에 게시한 결과 회수는 이 처리 범위에 포함하지 않습니다.
3. 계정 이용은 즉시 종료합니다. 파일·AI 정리가 지연되면 `개인정보 정리 중`을 표시하고 실제 정리를 확인한 뒤 `탈퇴 완료`로 표시합니다. 소유를 확인할 수 없는 과거 자료는 완료로 먼저 표시하지 않습니다.
4. 탈퇴 취소 유예기간은 없습니다. 정리 대기 중에도 같은 이메일·카카오로 새 계정을 만들 수 있지만 이전 소속·PM 권한은 복구하지 않으며 다시 참여하려면 새 초대가 필요합니다.
5. 이 약관을 어기면 운영자는 이용을 제한할 수 있습니다.

## 제12조 책임의 제한

1. 운영자는 고의나 과실로 이용자에게 손해를 끼치면 관련 법령에 따라 배상합니다.
2. 천재지변, 외부 서비스 장애, 이용자의 행위와 관련한 책임도 원인과 관련 법령에 따라 판단합니다. 이 약관이나 이용자의 동의만으로 운영자의 법정 개인정보 보호 의무와 책임이 면제되지는 않습니다.

## 제13조 분쟁 해결

이 약관은 대한민국 법을 따르며, 분쟁은 민사소송법이 정한 관할 법원에서 해결합니다.

## 제14조 문의

서비스 이용과 개인정보 문의는 `managersmanager.noreply@gmail.com`으로 받습니다. 개인정보 권리 요청 방법은 [개인정보처리방침 8항](privacy.md#8-이용자의-권리)을 따릅니다.

## 부칙

이 약관의 시행일은 실제 서비스 게시 시 명시합니다. 제품 정책 확정과 최종 서비스 게시·동의 수집 활성화는 구분합니다.

제품 결정과 구현·게시 상태는 [정책 안내](README.md)에 있습니다. 외부 업체 조건, 국외 이전 처리 근거, 책임자 표시 요건, 기존 제3조의 변경 공지·재동의 문구와 제12조·제13조의 법률 적정성을 확인 완료로 표시하지 않습니다.
