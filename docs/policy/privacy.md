# 개인정보처리방침

> 법률 검토 전 초안입니다. 서비스의 최종 정책으로 공개하거나 동의 수집에 사용하지 않습니다. `[정할 것]`과 `[확인 필요]`는 공개 전에 확인할 항목입니다.

- 초안 식별값: 2026-11-08
- 공개 버전·시행일: [정할 것: 본문 검토와 공개 승인 후 확정]

`2026-11-08`은 [동의 API 제안 PR #569](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/pull/569)의 `CURRENT_VERSIONS`와 같은 초안 식별값입니다. 최종 공개 때는 검토를 마친 본문의 새 버전을 정하고 BE의 동의 버전과 FE의 표시 버전을 함께 갱신합니다. 초안 버전으로 만든 테스트 동의 기록은 최종 본문에 대한 동의로 간주하지 않습니다.

Manager's Manager(이하 "운영자")는 Manager's Manager(이하 "서비스")를 운영합니다. 이 초안은 확정된 제품 정책과 현재 코드의 처리 범위를 기록하며, 법률 검토나 운영 검증의 완료를 뜻하지 않습니다.

## 1. 처리 목적

| 목적 | 내용 |
|---|---|
| 회원 관리 | 가입, 로그인, 본인 확인, 비밀번호 재설정 |
| 회의 정리 | 회의 음성을 글로 옮기고, 할 일과 변경 사항을 찾아 회의록과 태스크 후보를 만듦 |
| 협업 기능 | 워크스페이스 팀원 관리, 담당자 연결, 리마인드 메시지, 알림 |
| 외부 연동 | 이용자가 연결한 Notion 에 태스크 반영, 디스코드 봇의 녹음과 메시지 |
| 안전한 운영 | 로그인 시도 제한, 오류 대응 |

## 2. 처리 항목

| 구분 | 항목 |
|---|---|
| 가입 | 이메일, 이름, 비밀번호(해시로 저장), 로그인 방식. 카카오 로그인은 카카오 계정 식별값과 프로필 이미지 주소 |
| 워크스페이스 | 팀원 표시 이름, 역할, 디스코드 사용자 ID, Notion 이름, 담당자 별칭 |
| 회의 | 회의 음성, 전사 문장과 화자·시각, 회의록, 찾아낸 할 일과 근거 문장 |
| 디스코드 채팅 | 워크스페이스에 연결한 채널의 메시지(할 일을 찾는 데 사용) |
| 메시지 | 리마인드 메시지와 답장 |
| 연동 | Notion·디스코드 연동 토큰 |
| 알림 | 브라우저 푸시 구독 정보(구독 주소와 암호화 키) |
| 자동 생성 | 로그인 세션, 로그인 시도 제한용 이메일·IP 정보(서버 메모리에 저장. 15분은 제한 판정에 쓰는 시간이며 최대 보관기간이 아님. 보관·파기 기준은 공개 전 확인 필요) |
| 탈퇴 정리 확인 | 이름·이메일을 포함하지 않는 요청 식별자, 요청 키의 해시, 파일·AI 정리 상태 |

## 3. 보유 기간과 파기

| 항목 | 보유 기간 |
|---|---|
| 계정·개인 연결 정보 | 탈퇴 접수 때 계정·모든 세션·푸시 구독·본인의 연동 식별자·팀원 프로필·별칭 삭제. 파일·AI 사본 정리는 별도 확인 |
| 회의 음성 | 확정 정책은 정리 완료 뒤 원본·파생 음성 삭제. 자동 정리 구현과 운영 반영은 [PR #568](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/pull/568) 확인 필요 |
| 처리하지 못한 디스코드 녹음 | 확정 정책은 처리 포기 뒤 7일 보관 후 삭제. 구현과 운영 반영은 PR #568 확인 필요 |
| 처리하지 못한 업로드 음성 | 실패한 웹 업로드 원본은 즉시 삭제하는 정책. 화자 지정 대기는 최대 7일이며, 미인계 음성의 24시간 정리는 [PR #567](https://github.com/kakaotechcampus-4/ktc4-kyungpook-3/pull/567)의 구현·운영 반영 확인 필요 |
| 전사·회의록 | 별도 자동 만료기간 없이 회의나 워크스페이스가 삭제될 때까지 보관. 회의 삭제의 운영 활성화 조건은 아래 참조 |
| 공동 태스크·이력·메시지 | 다른 구성원이 남은 공간에서는 보존하고 탈퇴 작성자를 `탈퇴한 사용자`로 표시. 단독 활성 공간의 탈퇴 때는 공간 기록과 함께 삭제 |
| 로그인 세션 | 7일. 만료된 세션은 주기적으로 삭제 |
| Notion 에 반영된 태스크 | 이용자의 Notion 에 남으며 이용자가 관리 |

마지막 PM은 로그인 가능한 다른 팀원에게 PM 권한을 넘긴 뒤 탈퇴합니다. 다른 활성 팀원이 있는데 넘길 사람이 없으면 탈퇴를 거절합니다. 유일한 활성 멤버인 공간은 권한 이전 없이 탈퇴하고 공간의 회의·태스크·메시지도 함께 삭제합니다. 활성 Discord 전용 팀원도 단독 여부에 포함합니다.

계정 접근은 즉시 종료합니다. 파일·AI 정리가 남으면 `개인정보 정리 중`을 표시하고 실제 정리를 확인한 뒤 `탈퇴 완료`로 표시합니다. 정리 실패·활성 작업·소유 근거가 불명확한 과거 자료는 완료로 먼저 표시하지 않습니다. 취소 유예기간은 없고, 정리 대기 중에도 같은 이메일·카카오로 새 계정을 만들 수 있습니다. 이전 소속·PM 권한은 복구하지 않으며 새 초대가 필요합니다.

공동 기록 참조와 재시도를 위한 비식별 Member·정리 영수증·삭제 표식은 남습니다. 이에 대한 보관·파기 기준의 법률 검토는 공개 전에 확인합니다. 공동 기록의 자유 본문·음성 전체를 자동 익명화하거나, 이미 Notion·Discord에 게시된 결과를 회수하는 기능은 이 로컬 정리 범위에 포함하지 않습니다. 다른 구성원이 사용하는 공동 연동도 계정 탈퇴만으로 일괄 철회하지 않습니다.

회의 삭제 기능이 활성화되면 전사·회의록·추출·근거를 삭제하고 이미 생성된 태스크는 유지합니다. 태스크에는 `원본 회의가 삭제되어 근거를 볼 수 없음`을 표시합니다. 여러 회의가 합쳐진 승인 대기 카드는 삭제한 회의의 기여만 제거하고 남은 회의 내용으로 재구성합니다. 현재 회의 삭제는 서버 설정의 기본값이 비활성입니다. 새 워커·과거 계보 대조·별도 테스트를 확인한 뒤 활성화하는 [운영 절차](../../deploy/README.md#회의-삭제-활성화-576)를 적용하며, 코드 병합만으로 운영에서 사용할 수 있다고 표시하지 않습니다.

## 4. 제3자 제공

서비스는 회의 정리와 이용자가 연결한 기능을 위해 5항의 외부 처리 경로로 정보를 전송합니다. 각 경로의 제3자 제공·처리 위탁·국외 이전 분류와 필요한 고지는 법률 검토 전 확인 사항입니다.

## 6. 학습에 쓰지 않음

서비스에서 받은 회의 음성, 전사, 메시지는 인공지능 학습과 모델 개선에 쓰지 않습니다. 회의 정리를 위해서만 처리합니다.

이는 운영자의 활용 방침입니다. 외부 공급사의 학습 사용·보관 조건까지 확인됐다는 뜻은 아닙니다.

## 7. 회의 참석자의 개인정보

녹음하거나 올린 회의에는 가입하지 않은 참석자의 음성이 들어 있을 수 있습니다. 회의를 녹음하거나 올리는 이용자가 참석자에게 미리 알리고 필요한 동의를 받아야 합니다. 현재 디스코드 봇은 녹음을 시작할 때와 참석자가 들어올 때 녹음·전사 사실을 채널에 알립니다. 외부 서비스 전송 안내를 봇 고지에 추가하는 작업과 운영 반영은 공개 전 확인 사항입니다. 참석자도 아래 창구로 자신의 정보에 대한 요청을 할 수 있습니다.

## 8. 이용자의 권리

이용자는 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 문의 방식은 11항의 Manager's Manager 이메일이며 실제 공개 주소·응답 절차는 미정입니다. 화면의 계정 탈퇴 처리와 공동 기록의 보존 범위는 3항을 따릅니다.

## 9. 안전성 확보 조치

- 비밀번호와 로그인 세션 토큰은 원문 대신 해시로 저장합니다.
- 로그인 시도 횟수를 제한합니다.
- 현재 음성 조회 API는 워크스페이스 PM 권한을 검사합니다. 화자 지정용 샘플 듣기와 별도의 일반 원본 듣기 기능은 구분하며, 후자는 이번 배포 범위에 없습니다.
- [확인 필요: 전송 구간 암호화, 저장 데이터 암호화, 접근 기록]

## 10. 쿠키

로그인을 유지하기 위해 세션 쿠키를 씁니다(최대 7일). 외부 로그인과 연동 중에는 요청을 확인하는 쿠키를 잠시 씁니다. 광고·분석 쿠키는 쓰지 않습니다. 브라우저에서 쿠키를 막으면 로그인할 수 없습니다.
