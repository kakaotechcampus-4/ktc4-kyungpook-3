# 개인정보처리방침

> 법률 검토 전 초안입니다. `[정할 것]` 은 #565 에서 정한 뒤 채웁니다. 버전과 시행일은 BE 의 동의 버전(`CURRENT_VERSIONS`)과 같아야 합니다.

- 버전: 2026-11-08
- 시행일: [정할 것]

[운영 주체](이하 "운영자")는 Manager's Manager(이하 "서비스")를 운영하면서 이용자의 개인정보를 「개인정보 보호법」에 따라 처리합니다.

## 1. 처리 목적

| 목적 | 내용 |
|---|---|
| 회원 관리 | 가입, 로그인, 본인 확인, 비밀번호 재설정 |
| 회의 정리 | 회의 음성을 글로 옮기고, 할 일과 변경 사항을 찾아 회의록과 태스크 후보를 만듦 |
| 협업 기능 | 워크스페이스 팀원 관리, 담당자 연결, 리마인드 메시지, 알림 |
| 외부 연동 | 이용자가 연결한 Notion 에 태스크 반영, 디스코드 봇의 녹음과 메시지 |
| 안전한 운영 | 로그인 시도 제한, 오류 대응 |

## 2. 처리 항목

| 구분 | 항목 |
|---|---|
| 가입 | 이메일, 이름, 비밀번호(해시로 저장), 로그인 방식. 카카오 로그인은 카카오 계정 식별값과 프로필 이미지 주소 |
| 워크스페이스 | 팀원 표시 이름, 역할, 디스코드 사용자 ID, Notion 이름, 담당자 별칭 |
| 회의 | 회의 음성, 전사 문장과 화자·시각, 회의록, 찾아낸 할 일과 근거 문장 |
| 디스코드 채팅 | 워크스페이스에 연결한 채널의 메시지(할 일을 찾는 데 사용) |
| 메시지 | 리마인드 메시지와 답장 |
| 연동 | Notion·디스코드 연동 토큰 |
| 알림 | 브라우저 푸시 구독 정보(구독 주소와 암호화 키) |
| 자동 생성 | 로그인 세션, 로그인 시도 기록(이메일·IP, 서버 메모리에만 최대 15분) |

## 3. 보유 기간과 파기

| 항목 | 보유 기간 |
|---|---|
| 계정 정보 | 탈퇴할 때까지. [정할 것: 탈퇴 처리] |
| 회의 음성 | 회의 정리가 끝나면 바로 삭제 |
| 처리하지 못한 디스코드 녹음 | 처리를 멈춘 뒤 7일 동안 다시 처리하는 데 쓰고 삭제 |
| 처리하지 못한 업로드 음성 | 실패하면 바로 삭제. 화자 지정을 기다리는 음성은 최대 7일, 처리를 시작하지 못한 음성은 최대 24시간 보관 |
| 전사, 회의록, 할 일 | [정할 것: 보관 기간] |
| 로그인 세션 | 7일. 만료된 세션은 주기적으로 삭제 |
| Notion 에 반영된 태스크 | 이용자의 Notion 에 남으며 이용자가 관리 |

파기할 때는 파일과 데이터베이스 기록을 복구할 수 없게 지웁니다.

## 4. 제3자 제공

운영자는 개인정보를 제3자에게 제공하지 않습니다. 이용자가 연결한 Notion 과 디스코드로 보내는 내용은 이용자의 요청에 따른 전송입니다.

| 받는 곳 | 국가 | 항목 | 목적 | 보관 |

국외 이전은 서비스를 이용할 때 네트워크로 전송하며, 해당 기능을 쓰지 않으면 이전되지 않습니다. 이전을 원하지 않으면 해당 연동을 끊거나 기능을 쓰지 않을 수 있습니다.

## 6. 학습에 쓰지 않음

서비스에서 받은 회의 음성, 전사, 메시지는 인공지능 학습과 모델 개선에 쓰지 않습니다. 회의 정리를 위해서만 처리합니다.

## 7. 회의 참석자의 개인정보

녹음하거나 올린 회의에는 가입하지 않은 참석자의 음성이 들어 있을 수 있습니다. 회의를 녹음하거나 올리는 이용자가 참석자에게 미리 알리고 필요한 동의를 받아야 합니다. 디스코드 봇은 녹음을 시작할 때와 참석자가 들어올 때 채널에 녹음 사실과 외부 서비스로 보낸다는 사실을 알립니다. 참석자도 아래 창구로 자신의 정보에 대한 요청을 할 수 있습니다.

## 8. 이용자의 권리

이용자는 언제든 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. [정할 것: 요청 창구]로 요청하면 지체 없이 처리합니다.

## 9. 안전성 확보 조치

- 비밀번호와 로그인 세션 토큰은 원문 대신 해시로 저장합니다.
- 로그인 시도 횟수를 제한합니다.
- 회의 원본 음성은 워크스페이스 PM 만 들을 수 있습니다.
- [확인 필요: 전송 구간 암호화, 저장 데이터 암호화, 접근 기록]

## 10. 쿠키

로그인을 유지하기 위해 세션 쿠키를 씁니다(최대 7일). 외부 로그인과 연동 중에는 요청을 확인하는 쿠키를 잠시 씁니다. 광고·분석 쿠키는 쓰지 않습니다. 브라우저에서 쿠키를 막으면 로그인할 수 없습니다.
