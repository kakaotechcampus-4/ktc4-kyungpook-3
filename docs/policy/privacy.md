판본: 2026-11-10 · 시행일: 2026-11-10

## 1. 운영 주체와 처리 목적

Manager's Manager는 팀원·멘토·심사위원 중심의 교육·평가용 시범 서비스를 운영합니다. 계정 관리, 회의 전사·정리, 태스크 생성·변경, 팀 협업·알림, 이용자가 연결한 외부 기능과 안전한 운영을 위해 정보를 처리합니다.

## 2. 처리하는 정보

계정: 이메일, 이름, 비밀번호 해시, 로그인 방식과 세션. 카카오 로그인 시 카카오 식별값과 제공받은 프로필 이미지 주소를 처리합니다.

팀과 연동: 워크스페이스 역할, 팀원 이름, Discord 사용자 ID, Notion 이름, 담당자 별칭, 연동 토큰과 브라우저 푸시 구독 정보를 처리합니다.

회의와 업무: 회의 음성, 전사문·화자·시각, 회의록, 태스크와 근거 문장, 연결된 Discord 채널의 메시지, 리마인드 메시지와 답장을 처리합니다.

운영과 정리: 로그인 시도 제한용 이메일·IP 정보, 문서 판본과 동의 시각, 개인정보 정리 요청 식별자와 처리 상태를 다룹니다. 실제 비밀번호·인증번호를 문의 메일에 보내지 마세요.

## 3. 수집 경로와 회의 참석자

가입·설정 입력, 카카오 로그인, 웹 음성 업로드, 연결한 Discord 녹음·채팅과 외부 연동을 통해 정보를 처리합니다. 회의에는 서비스에 가입하지 않은 참석자의 음성과 이름이 포함될 수 있습니다.

녹음·업로드하는 이용자는 참석자에게 녹음·전사·외부 AI 전송을 미리 알리고 필요한 동의를 확보해야 합니다. 서비스의 업로드 안내와 Discord 녹음 고지 자체를 모든 참석자의 동의로 간주하지 않습니다. 참석자도 문의 이메일로 권리를 요청할 수 있습니다.

## 4. 우리 서비스의 보관·삭제 기준

성공 인계한 회의의 원본·파생 음성은 삭제합니다. 처리 포기한 Discord 음성은 7일 뒤 삭제합니다. 실패한 웹 업로드 원본은 즉시 삭제하고, 미인계 업로드는 24시간 정리 대상이며 화자 지정 대기는 최대 7일입니다.

전사·회의록은 별도 자동 만료 없이 회의나 워크스페이스가 삭제될 때까지 보관합니다. 로그인 세션의 유효기간은 최대 7일입니다. 외부 업체에 전송된 사본과 외부 게시물의 보관은 아래 업체별 안내와 구분합니다.

로그인 제한의 15분은 시도 횟수를 판단하는 기간이며 해당 정보의 최대 보관기간이라는 뜻은 아닙니다. 운영 로그·동의 기록·정리 영수증·삭제 표식·백업의 일률적인 파기 일수는 현재 안내할 수 있도록 확정되지 않았습니다. 보관 범위와 삭제 요청은 문의 이메일로 확인할 수 있습니다.

## 5. 탈퇴와 회의 삭제

탈퇴 접수 시 계정 접근과 모든 세션을 종료하고 개인 연결 정보·푸시 구독·팀원 프로필·별칭을 삭제합니다. 다른 멤버가 남은 공동 기록은 보존하고 구조화된 작성자는 탈퇴한 사용자로 표시합니다. 본문·음성 전체의 자동 익명화와 이미 Notion·Discord에 게시한 내용의 일괄 회수는 포함하지 않습니다.

다른 활성 멤버가 있는 공간의 마지막 PM은 권한 이전이 필요합니다. 유일한 활성 멤버이면 공간과 그 안의 회의·태스크·메시지도 삭제합니다. 재가입은 즉시 새 계정으로 가능하며 이전 소속·역할은 복원하지 않습니다.

파일·AI 정리가 지연되거나 소유 관계를 확인해야 하면 개인정보 정리 중으로 표시하고 실제 정리를 확인한 뒤 완료로 표시합니다. 이 상태에서도 새 계정 가입은 가능합니다. 남는 정리 식별자가 모두 법적으로 익명정보라는 뜻은 아닙니다.

개별 회의 삭제는 현재 일반 이용 화면에서 제공하지 않으므로 문의 이메일로 요청해 주세요. 삭제 처리 시 전사·회의록·추출·근거는 지우고 생성된 태스크는 원본 삭제 상태로 유지합니다. 합쳐진 승인 대기 카드에서는 삭제 회의의 기여만 제거합니다.

## 6. 외부 AI 처리: Elice

회의 음성, 전사문, 태스크 제목과 관련 메시지·문맥을 Elice ML API에 보내 전사, 할 일 추출·판정, 회의 요약, 메시지 작성, 근거 검색과 임베딩에 사용합니다. 입력에 이름과 담당자 정보가 포함될 수 있습니다.

Elice의 공식 ML API 활용 가이드는 소개한 구성에서 국내 클라우드 처리를 설명합니다. 이 설명이 우리 서비스의 모든 STT·요약·임베딩 엔드포인트와 설정에 동일하게 적용된다는 확인까지 완료한 것은 아닙니다.

Elice 일반 개인정보처리방침에는 목적 달성·보유기간 만료 시 파기 원칙이 있습니다. 다만 우리 API 입력·응답·로그·캐시·백업의 정확한 보관 기간과 학습 이용 여부는 검토한 공개 자료에서 확인하지 못했습니다. 이를 무보관·학습 미사용으로 보장하지 않습니다. 아래 공식 자료에서 업체 정책을 확인할 수 있습니다.

장애 시 사용 가능한 GPU 전사 대체 경로의 운영 주체·처리 위치·보관·삭제 조건도 모든 범위의 확인이 완료된 상태는 아닙니다. 우리 서버의 음성 삭제가 외부 업체 사본의 삭제를 의미하지는 않습니다.

## 7. 외부 AI 처리: pyannoteAI

웹으로 올린 회의 음성과 작업 요청 정보를 Pyannote SAS의 pyannoteAI에 보내 화자를 구분합니다. 운영 계정의 EU 지역 설정 변경 완료 보고를 받았습니다. 공식 안내상 이 설정은 EEA 내 처리를 의미하며 개별 처리 국가를 특정한 확인은 아닙니다.

공식 보관 안내상 Media API 업로드 음성은 48시간 이내, 작업 결과는 완료 후 24시간 뒤 삭제하며 처리 워커의 음성 사본은 처리 후 삭제합니다. DPA는 요청 입력·설정·참조와 메타데이터의 별도 보관을 설명하며 계약 기간과 종료 후 18개월 보관 항목이 있습니다. 모든 데이터가 48시간 안에 삭제된다는 뜻은 아닙니다.

공식 자료는 고객 데이터의 모델 학습 미사용을 설명합니다. 지원 요청에 별도 동의해 공유하는 예시는 검증·테스트에 이용될 수 있습니다. 입력 범위·백업·삭제 예외의 모든 조건까지 별도 확인을 마친 것은 아니며 아래 공식 보관 안내·DPA를 함께 확인해 주세요.

## 8. 서버와 기타 외부 연동

AWS: 대한민국 서울 리전의 서비스 서버에서 계정·회의·태스크·메시지와 연동 정보를 처리합니다. 별도 백업·운영 로그의 모든 보관·접근 경로를 동일하다고 보장하는 것은 아닙니다.

Notion: 이용자가 연결한 공간에 태스크 제목·상태·담당자·마감일 등을 반영합니다. Discord: 연결한 채널의 음성·채팅·사용자 식별자와 봇 메시지를 처리합니다. 이미 외부에 반영된 기록은 우리 서버의 삭제와 별개이며 해당 서비스에서도 관리해야 합니다.

인증·복구 메일은 SMTP 발송 서비스를 사용하고, Gmail 경로에는 Google 정책이 적용됩니다. 브라우저 알림은 브라우저·기기의 푸시 서비스와 구독·알림 전송 정보를 처리합니다. 카카오 로그인에는 카카오의 인증·개인정보 정책도 적용됩니다.

외부 업체별 실제 처리 국가·재위탁·잔여 보관·삭제 조건을 모두 개별 확인한 상태는 아닙니다. 아래 공식 자료와 문의 창구를 통해 적용 범위를 확인할 수 있습니다.

## 9. 외부 전송·국외 처리와 거부

해당 기능을 이용하는 처리 시점에 네트워크 API로 정보를 전송합니다. pyannoteAI 등의 경로에서는 국외 처리가 발생합니다. 업체별 확인된 위치·항목·목적·보관 범위는 위 설명과 공식 자료를 함께 봐 주세요.

외부 AI 전송을 원하지 않으면 회의 업로드·녹음 처리를 시작하지 말고 문의 이메일로 처리정지를 요청할 수 있습니다. 해당 전송이 필요한 AI 정리 기능은 제공할 수 없습니다. 이미 전송된 자료의 삭제 가능 범위는 업체 조건과 구분해 안내합니다.

이 방침 확인을 별도 동의가 필요한 국외 이전이나 제3자 제공의 포괄 동의로 간주하지 않습니다. 구체적인 처리 근거와 필요한 별도 고지·동의는 해당 처리의 실제 조건에 따라 적용해야 합니다. 공개되지 않은 업체 조건을 이용자가 확인했다고 기록하지 않습니다.
