## 외부 업체 정보의 확인 기준

실제 사용하는 API·요금제·계정 설정에 적용되는 공식 문서나 계약을 확인한다. 업체·항목·목적·보관 기간·처리 국가·연락처와 전송 시점·방법을 요약하고, 적용 범위와 확인 날짜를 남긴다. 공식 자료로 필요한 사실을 확인할 수 있으면 그 자료를 사용한다. 정보가 없거나 모호한 부분만 기존 담당 작업으로 확인하며, 모든 업체의 별도 회신을 일률적으로 요구하지 않는다.

국외 이전을 별도 동의에 근거해 처리하는 경우에는 이전 항목, 국가·시기·방법, 받는 업체와 연락처, 목적·보유기간, 거부 방법·절차·효과를 미리 안내한다. 계약 이행에 필요한 위탁·보관 등 다른 근거의 적용 가능성은 실제 흐름에 대조한다. [개인정보 보호법 제28조의8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331957)을 기준으로 하며, 이번 문서에서 특정 근거가 충족됐다고 단정하지 않는다.
